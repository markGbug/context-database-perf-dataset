## 动态内存分配：brk 系统调用

sys_brk（系统调用号 45）通过调整程序的 数据段边界（program break） 来分配/释放内存。

program break 是数据段（包括 .data、.bss 和堆）的结束位置，在其之上的内存程序不能访问。


## 实例

sys_brk 只能调整连续的数据段边界，不能释放中间的内存。要释放某块已分配的内存，必须先释放之后分配的所有内存。这就是为什么现代程序更多使用 mmap 或 malloc 库函数。
