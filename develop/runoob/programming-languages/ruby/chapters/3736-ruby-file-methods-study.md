## 本章内容

File 表示一个连接到普通文件的 stdio 对象。open 为普通文件返回该类的一个实例。


## 类方法

- file - 普通文件
- directory - 目录
- characterSpecial - 字符特殊文件
- blockSpecial - 块特殊文件
- fifo - 命名管道（FIFO）
- link - 符号链接
- socket - Socket
- unknown - 未知的文件类型
