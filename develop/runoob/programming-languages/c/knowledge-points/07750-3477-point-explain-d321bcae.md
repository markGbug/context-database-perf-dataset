## 原文片段

C 语言是一种通用的高级编程语言，最初由丹尼斯·里奇（Dennis Ritchie）在贝尔实验室为开发 UNIX 操作系统而设计。C 语言于 1972 年在 DEC PDP-11 计算机上首次实现，是现代编程语言体系中最具影响力的语言之一。
