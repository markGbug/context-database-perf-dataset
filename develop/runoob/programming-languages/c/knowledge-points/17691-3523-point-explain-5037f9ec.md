## 原文片段

<setjmp.h> 是 C 标准库中的一个头文件，提供了一组函数和宏，用于非本地跳转（即从一个函数跳转到另一个之前调用过的函数，而不需要正常的函数返回机制）。这种机制通常用于错误处理、异常处理或者跳出深层嵌套的循环或递归。
