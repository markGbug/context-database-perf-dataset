## 原文片段

UNIX 操作系统、C 编译器以及几乎所有的 UNIX 应用程序都是用 C 语言编写的。凭借其简洁的语法、接近硬件的控制能力和出色的运行效率，C 语言已成为系统编程领域最重要的专业语言，并深刻影响了 C++、Java、Go、Rust 等众多后继语言的设计。
