## 原文片段

<stdbool.h> 是 C 语言中的一个标准头文件，定义了布尔类型及其相关的常量。它使得 C 语言的布尔类型（bool）变得更加明确和可用，避免了使用整数（如 0 或 1）来表示布尔值的传统做法。
