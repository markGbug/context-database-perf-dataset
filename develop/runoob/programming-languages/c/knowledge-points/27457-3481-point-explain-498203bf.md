## 原文片段

在 C 语言中，令牌（Token）是程序的基本组成单位，编译器通过对源代码进行词法分析，将代码分解成一个个的令牌。令牌是编译器能识别的最小有意义单元，整个 C 程序都由这些令牌构成。
