### 注意事项

- 使用 fopen 打开文件后，务必使用 fclose 关闭文件，以避免文件资源泄漏。
- 使用 fgets 读取字符串时，务必注意缓冲区的大小，以避免缓冲区溢出。
- 使用 printf、scanf 等函数时，务必注意格式化字符串的正确性，以避免未定义行为。
