## 原文片段

文件操作前后务必检查系统调用的返回值（在 EAX 中）。负值表示错误（如 -2 是 ENOENT 文件不存在，-13 是 EACCES 权限不足），忽略错误返回值是文件操作 bug 的最大来源。
