## 原文片段

<cassert> 是 C++ 标准库中的一个头文件，它提供了断言功能，用于在程序运行时检查条件是否为真。如果条件为假，程序将终止执行，并输出一条错误信息。断言主要用于调试阶段，以确保程序的逻辑正确性。
