## 原文片段

<codecvt> 是 C++ 标准库中的一个头文件，提供了字符转换的工具。这个头文件主要包含 std::codecvt 类模板及其特化，支持字符编码之间的转换，例如从 UTF-8 到 UTF-16，或从宽字符（wchar_t）到窄字符（char）等。std::codecvt 类通常与 std::wstring_convert 类一起使用，以实现字符编码转换。
