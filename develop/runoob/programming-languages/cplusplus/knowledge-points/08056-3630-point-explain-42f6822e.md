## 原文片段

<cwchar> 是 C++ 标准库中的一个头文件，提供了处理宽字符（wchar_t）和宽字符串的函数。这些函数大部分来自 C 标准库的 <wchar.h>，用于处理宽字符的输入输出、内存操作、字符串操作和其他与宽字符相关的功能。
