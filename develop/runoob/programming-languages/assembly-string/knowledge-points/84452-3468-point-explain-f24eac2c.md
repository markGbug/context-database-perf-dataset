## 原文片段

方向标志 DF 决定了字符串操作的方向：DF=0 时 ESI/EDI 递增（正向），DF=1 时递减（反向）。用 CLD 清零 DF，用 STD 置位 DF。在调用 C 函数或系统调用前应该确保 DF=0（cdecl 要求）。
