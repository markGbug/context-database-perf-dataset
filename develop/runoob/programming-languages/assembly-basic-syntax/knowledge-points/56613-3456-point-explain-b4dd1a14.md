## 原文片段

NASM 使用 分号（;） 表示注释，从分号到行尾的内容都会被汇编器忽略。

## 学习理解

这是本章正文中的解释型知识点。复习时应先确认关键词，再用自己的话复述它解决的问题。

- 这句话定义了什么？
- 它解释的是原因、规则、场景还是限制？
- 能否用一个小例子验证或说明？
