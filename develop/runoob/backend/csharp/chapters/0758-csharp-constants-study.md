## 本章内容

常量（Constant）是在程序中定义后不能重新赋值的值，通常用于表示固定不变的数据，例如圆周率、最大连接数、状态标识等。

在 C# 中，可以使用 const 关键字声明编译时常量，也可以通过整数、浮点数、字符、字符串等字面量直接表示固定值。

本章节主要介绍 C# 中常见的常量类型、字面量写法，以及如何使用 const 定义常量。


## 整数常量

整数常量用于表示没有小数部分的整数。在 C# 中，整数字面量支持以下三种进制：

- 十进制：直接使用数字表示，例如 100、255。
- 十六进制：使用 0x 或 0X 前缀，例如 0xFF。
- 二进制：使用 0b 或 0B 前缀，例如 0b1010。

注意：C# 不支持 C/C++ 中通过前导数字 0 表示八进制整数的写法。例如，0213 在 C# 中表示十进制整数 213，而不是八进制数。

以下是一些合法的整数常量：

```text
212           // 十进制整数
0xFF          // 十六进制，等于十进制 255
0b1010        // 二进制，等于十进制 10
215U          // 无符号整数
100L          // long 类型整数
100UL         // ulong 类型整数
1_000_000     // 使用下划线分隔数字，提高可读性
```

以下是一些不合法的整数常量：

```text
0b102         // 非法：二进制只能包含 0 和 1
0xFG          // 非法：G 不是十六进制数字
032UU         // 非法：不能重复使用 U 后缀
123_          // 非法：下划线不能放在数字末尾
```

## 浮点常量

浮点常量用于表示带有小数部分或采用科学计数法表示的数值，例如 3.14、0.5 和 1.5e3。

在 C# 中，浮点数字面量可以包含整数部分、小数部分和指数部分，也可以使用科学计数法表示。

科学计数法使用 e 或 E 表示以 10 为底的指数，例如：

```text
1.5e3     // 1.5 × 10³，即 1500
2.5E-2    // 2.5 × 10⁻²，即 0.025
```

C# 提供三种常用的浮点数类型：

以下是一些合法的浮点常量：

```text
3.14159       // 合法，double 类型
3.14f         // 合法，float 类型
3.14m         // 合法，decimal 类型
314159E-5     // 合法，科学计数法
210f          // 合法，float 类型，值为 210
1.5e3         // 合法，值为 1500
0.25D         // 合法，double 类型
```

以下是不合法的浮点常量：

```text
510E          // 非法：指数部分缺少数字
.e55          // 非法：小数点前后都没有有效数字
3.14L         // 非法：L 只能作为整数后缀
1.2.3         // 非法：包含多个小数点
```

注意：没有后缀的实数字面量默认是 double 类型。如果要将带小数的字面量赋值给 float 或 decimal 变量，通常需要添加 f 或 m 后缀。

## 字符串常量

字符串用于表示一组字符。在 C# 中，字符串类型为 string，普通字符串字面量使用双引号 "" 包围。

C# 支持普通字符串、逐字字符串、插值字符串以及原始字符串等多种写法。

1、普通字符串

普通字符串使用双引号表示，支持 \n、\t、\\ 等转义序列。

```text
string a = "hello, world";
string b = "Hello\nWorld";
string c = "Joe said \"Hello\" to me";
string d = "C:\\Users\\Public\\Documents";
```

2、逐字字符串

逐字字符串在双引号前添加 @，通常不需要对反斜杠进行转义，特别适合表示 Windows 文件路径、正则表达式等内容。

```text
string a = @"hello, world";
string b = @"C:\Users\Public\Documents";
string c = @"Joe said ""Hello"" to me";
string d = @"\\server\share\file.txt";
```

在逐字字符串中，反斜杠按普通字符处理。如果需要包含双引号，可以使用两个连续的双引号 ""。

3、插值字符串

插值字符串使用 $ 前缀，可以直接将变量或表达式嵌入字符串中，避免频繁使用字符串拼接。

```java
string name = "Runoob";
int age = 10;

string message = $"名称：{name}，年龄：{age}";
```

4、原始字符串

从 C# 11 开始，可以使用三个或更多双引号定义原始字符串字面量（Raw String Literal）。

原始字符串可以直接包含反斜杠和双引号，适合表示 JSON、HTML、SQL 等多行文本。

```text
string json = """
{
    "name": "Runoob",
    "language": "C#"
}
""";
```

以上代码中的双引号不需要使用反斜杠转义。原始字符串中的换行与缩进遵循 C# 原始字符串的语法规则。

## 定义常量

在 C# 中，可以使用 const 关键字定义常量。

常量必须在声明时进行初始化，并且初始化表达式必须是编译时能够确定的常量表达式。一旦定义，不能重新赋值。

定义常量的基本语法如下：

```javascript
const 数据类型 常量名称 = 常量表达式;
```

例如：

```java
const int MaxCount = 100;
const double Pi = 3.1415926;
const string SiteName = "Runoob";
const bool IsEnabled = true;
```

需要注意，const 并不能用于所有数据类型。通常可以用于数值类型、bool、char、string 和枚举类型。其他引用类型只能声明值为 null 的常量。

对于需要在程序运行时确定初始值的数据，可以考虑使用 readonly。


总结：C# 中的字面量用于直接表示固定值，而 const 可以为编译时常量指定具有明确含义的名称。对于编译时能够确定且长期不变的值，可以使用 const；对于需要在运行时初始化、之后不允许重新赋值的字段，可以使用 readonly。
