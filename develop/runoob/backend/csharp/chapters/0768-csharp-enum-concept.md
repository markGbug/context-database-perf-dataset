## 本章内容

枚举是一组命名整型常量。枚举类型是使用 enum 关键字声明的。

C# 枚举是值类型。换句话说，枚举包含自己的值，且不能继承或传递继承。


## 声明 enum 变量

声明枚举的一般语法：

```html
enum <enum_name>
{
    enumeration list
};
```

其中，

- enum_name 指定枚举的类型名称。
- enumeration list 是一个用逗号分隔的标识符列表。

枚举列表中的每个符号代表一个整数值，一个比它前面的符号大的整数值。默认情况下，第一个枚举符号的值是 0.例如：

```text
enum Days { Sun, Mon, tue, Wed, thu, Fri, Sat };
```
