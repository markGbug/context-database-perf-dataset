## VBScript 子程序

子程序：

- 是一系列的语句，被封装在 Sub 和 End Sub 语句内
- 可执行某些操作，但不会返回值
- 可带有参数

## VBScript 函数程序

函数程序

- 是一系列的语句，被封装在 Function 和 End Function 语句内

- 可带有通过程序调用来向其传递的参数。
- 如果没有参数，必须带有空的圆括号 ()
- 通过向函数程序名赋值的方式，可使其返回值
