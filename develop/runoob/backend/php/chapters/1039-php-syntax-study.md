## 基本的 PHP 语法

PHP 脚本可以放在文档中的任何位置。

PHP 脚本以 <?php 开始，以 ?> 结束：

```text
<?php
// PHP 代码
?>
```

PHP 文件的默认文件扩展名是 .php。

PHP 文件通常包含 HTML 标签和一些 PHP 脚本代码。

## PHP 中的注释

在 PHP 中，注释用来解释代码的作用，不会被执行，也不会输出到页面上。

注释主要有三种形式：


### 1、单行注释（2 种写法）

使用 //

```text
<?php
// 这是单行注释
echo "Hello"; // 也可以放在语句后面
?>
```

使用 #

```text
<?php
# 这是另一种单行注释
echo "World";
?>
```

特点：

- 从 // 或 # 开始，到本行结束为止。
- 常用于简短说明。
