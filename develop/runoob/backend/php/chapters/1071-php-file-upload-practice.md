## 本章内容

通过 PHP，可以把文件上传到服务器。

本章节实例在 test 项目下完成，目录结构为：

```text
test
|-----upload             # 文件上传的目录
|-----form.html          # 表单文件
|-----upload_file.php    # php 上传代码
```
