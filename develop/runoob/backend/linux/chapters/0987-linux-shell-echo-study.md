## Shell echo 命令

echo 是一个内置的 Shell 命令，用于在标准输出（通常是终端）显示一行文本或变量的值。

Shell 的 echo 指令与 PHP 的 echo 指令类似，都是用于字符串的输出。

命令格式：

```bash
echo [选项] [字符串]
```

### 为什么需要 echo？

- 信息反馈：向用户显示脚本执行状态或结果
- 调试工具：输出变量值或执行位置，帮助调试脚本
- 交互界面：创建简单的用户交互界面
- 文件生成：快速生成配置文件或脚本
