## 本章内容

Swagger (OpenAPI) 是一种用于描述、生成和可视化 RESTful Web 服务的规范和工具集。

下面我将详细介绍如何从零开始编写你的第一个 Swagger 文档。

Swagger 文档主要采用 YAML 或 JSON 格式，定义了 API 的各个方面，包括：

- API 基本信息（标题、版本等）
- 可用路径和操作
- 输入参数和输出响应
- 验证方式
- 数据模型定义


## 创建步骤


### 1. 创建基本文件结构

首先，创建一个名为 swagger.yaml 或 swagger.json 的文件。本教程以 YAML 格式为例，因为它更易于阅读和编写。
