## 原文片段

Swagger最早由 Wordnik 的联合创始人 Tony Tam 在 2011 年创建。它通过简洁的 JSON 或 YAML 格式描述 API 结构，使得 API 的设计、实现和测试更加高效直观。Swagger 后来演变为 OpenAPI Specification，并成为业界广泛接受的标准。
