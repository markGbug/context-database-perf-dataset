## 原文片段

想象一下，你平时用浏览器访问网站时，看到的是由 HTML 构建的页面，用 CSS 美化样式，用 JavaScript 实现交互功能。Electron 就像是把一个浏览器打包"起来，让它能够独立运行，不再需要用户手动打开浏览器。
