## 原文片段

ASP 与 VBScript 和 JScript（JScript 是微软的 JavaScript 实现）的配合是原生性的。如果您想要使用其他语言编写脚本，比如 PERL、REXX 或者 Python，您必须安装相应的脚本引擎。
