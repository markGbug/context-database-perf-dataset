## 本章内容

当你开始写 Node.js 项目时，最先遇到的问题之一就是——如何导入模块（module）。

在 Node.js 里，模块就是可以重复使用的 JavaScript 文件，它们之间通过导入（import）和导出（export）互相通信。

Node.js 生态系统主要支持两种模块系统：CommonJS 和 ES Modules (ESM)。
