## 原文片段

作为 Node.js 开发者，你一定听说过 npm 和 yarn，它们是管理项目依赖的利器。但你是否遇到过 node_modules 文件夹巨大无比、安装速度缓慢、或者磁盘空间被迅速占满的烦恼？这就是 pnpm 能解决的问题。
