## 本章内容

SFTP（SSH File Transfer Protocol，SSH 文件传输协议）是一种基于 SSH（Secure Shell）的文件传输协议，用于在客户端和服务器之间安全地传输文件。

与传统的 FTP 不同，SFTP 通过加密通信保护数据传输，适合传输敏感信息。
