## 原文片段

解释器模式（Interpreter Pattern）是一种行为型设计模式，它定义了一个语言的文法，并建立一个解释器来解释该语言中的句子。简单来说，它就像是一个小型编译器，能够解析和执行特定语法规则的表达式。
