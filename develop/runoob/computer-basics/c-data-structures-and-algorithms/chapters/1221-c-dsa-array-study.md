## 本章内容

数组（Array）是最基础、也是最常用的数据结构之一。

数组是一组类型相同、在内存中连续存放的元素集合。


## 数组的定义与内存布局

在 C 语言中，数组声明后会在内存中分配一块连续的空间，每个元素可以通过下标直接访问。
