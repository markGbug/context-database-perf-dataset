## 本章内容

堆（Heap）是一种特殊的完全二叉树结构，满足堆序性质。堆只保证父子节点之间的大小关系，不要求左右子树之间存在严格的顺序。


## 堆的定义与存储

父:(i-1)/2 | 左子:2i+1 | 右子:2i+2

完全二叉树 → 天然适合数组，无指针开销

新元素放末尾 → 与父比较 → 若大则交换 → 重复至堆顶

末尾元素移堆顶 → 与较大子比较 → 若小则交换 → 重复至叶

堆的两种类型：

- 最大堆（Max Heap）：每个父节点 ≥ 子节点，根节点为最大值
- 最小堆（Min Heap）：每个父节点 ≤ 子节点，根节点为最小值
