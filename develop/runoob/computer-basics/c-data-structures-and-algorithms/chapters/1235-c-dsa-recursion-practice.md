## 递归与迭代对比

尾递归是一种特殊形式的递归，即递归调用是函数体中执行的最后一个操作。某些编译器能对尾递归进行优化，将其转换为等价迭代以节省栈空间。但并非所有 C 编译器都默认开启此项优化。
