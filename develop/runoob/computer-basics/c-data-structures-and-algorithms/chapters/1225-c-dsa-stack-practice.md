## 本章内容

栈（Stack）是一种遵循后进先出（Last In First Out，LIFO）原则的线性数据结构，可以形象地理解为一摞叠放的盘子——只能从最上面放入，也只能从最上面取走。


## 栈的概念与原理

LIFO 验证：入栈 10→20→30，出栈 30→20→10（后进先出）| 栈只关心栈顶，不关心中间

存储：固定大小数组 + top 指针

push：items[++top] = value

pop：return items[top--]

优点：访问快，缓存友好，实现简单

缺点：容量固定，可能溢出

存储：动态节点 + 栈顶指针(链表头)

push：头插法 newNode->next = top

pop：top = top->next; free(旧头)

优点：无容量限制，灵活动态扩展

缺点：额外指针开销，缓存不友好
