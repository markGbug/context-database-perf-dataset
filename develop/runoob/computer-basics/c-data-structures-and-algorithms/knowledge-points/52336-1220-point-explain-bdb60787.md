## 原文片段

同一种逻辑结构可以用不同的存储方式来实现。例如，栈（逻辑上是线性结构）既可以用数组（顺序存储）实现，也可以用链表（链式存储）实现。选择哪种实现方式取决于具体应用场景对访问速度、增删效率和内存占用的不同要求。
