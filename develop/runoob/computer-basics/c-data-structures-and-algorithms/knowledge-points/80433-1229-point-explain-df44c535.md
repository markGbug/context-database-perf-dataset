## 原文片段

BST 在理想情况下（树保持平衡），插入、删除、查找都可达 O(log n)。但如果数据本身有序（如按 1, 2, 3, 4... 插入），BST 会退化为一条链表，效率降为 O(n)。为解决此问题，计算机科学中发展出了 AVL 树等自平衡二叉搜索树。
