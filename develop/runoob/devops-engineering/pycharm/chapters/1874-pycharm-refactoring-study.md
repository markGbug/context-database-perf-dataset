## 本章内容

代码重构是指在不改变代码外部行为的前提下，优化代码内部结构的过程。

重构的目的是提高代码的可读性、可维护性和可扩展性，而不是添加新功能或修复 Bug。

PyCharm 为 Python 开发者提供了一套强大且安全的自动化重构工具，让重构变得高效且不易出错。

## 一键调出重构菜单

如果你记不住各种重构操作的快捷键，可以使用万能快捷键 Ctrl + Alt + Shift + T（macOS 为 Command + Option + Shift + T）调出重构菜单。

该菜单会列出当前光标位置可用的所有重构操作，你只需在菜单中选择即可。

这种方式适合不常用的重构操作，或者作为初学者的过渡方案。


## 重构前的预览功能

在执行重构之前，PyCharm 提供了 Preview 预览功能，让你可以在确认前全面了解重构的影响范围。

当你按下重构快捷键后，PyCharm 会弹出一个对话框，其中包含 Preview 按钮。

点击 Preview 按钮，PyCharm 会在底部打开一个对比窗口，左侧是修改前的代码，右侧是修改后的代码。

你可以逐条审查每一处修改，决定保留或跳过，确认无误后再点击 Do Refactor 执行重构。

强烈建议在对大型项目或核心模块进行重构时使用 Preview 功能，避免意外修改导致的 Bug。


## 重构注意事项

虽然 PyCharm 的重构工具非常可靠，但在重构时仍需注意以下几点。

- 重构前确保代码已提交到版本控制系统，以便出现意外时可以回滚。
- 重构后立即运行已有的单元测试，确保行为没有改变。
- 一次只做一种重构操作，避免同时修改过多内容导致混淆。
- 如果重构涉及公共 API，请确认所有调用方都已纳入重构范围。

掌握这些重构技巧，你的代码将始终保持整洁、清晰和易于维护。
