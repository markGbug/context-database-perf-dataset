## 本章内容

单元测试是保证代码质量的基础手段，它验证程序中最小可测试单元的行为是否符合预期。

在 PyCharm 中编写和运行单元测试非常便捷，IDE 提供了从测试创建到执行再到结果分析的完整工作流。

PyCharm 内置支持三种主流 Python 测试框架：unittest、pytest 和 nose。

## 实例

PyCharm 可以自动识别测试类和测试方法，测试类名以 Test 开头，测试方法名以 test_ 开头是 Python 测试的命名约定。


## 运行测试

编写好测试代码后，有多种方式可以运行测试。


### 方式一：点击绿色运行图标

PyCharm 会在测试类和每个测试方法的左侧 Gutter 区域显示绿色运行图标。

点击类名旁的绿色图标可以运行该类的所有测试，点击方法旁的图标只运行单个测试。

也可以右键点击测试文件，在菜单中选择 Run 'test_car'。


### 方式二：使用快捷键

将光标放在测试类或测试方法内部，按下 Ctrl + Shift + F10 即可运行当前测试。


### 查看测试结果

测试运行完成后，PyCharm 会在底部的 Run 工具窗口中树状显示测试结果。

通过的测试以绿色对勾标记，失败的测试以红色叉号标记，并附带详细的错误信息和堆栈跟踪。

点击失败的测试项，PyCharm 会直接跳转到出错的代码行，方便快速定位问题。


## 切换测试框架

PyCharm 默认使用 unittest 作为测试运行器，但你可以轻松切换到其他框架。


### 配置步骤

- 打开 设置（快捷键 Ctrl + Alt + S，macOS 为 Command + ,）。
- 导航到 Python。
- 在 集成工具 区域找到 测试 下拉菜单。
- 从 Unittests、pytest、Nosetests 中选择你需要的框架。
- 点击 确认 保存设置。

如果选择 pytest 作为测试运行器，请确保已通过 pip install pytest 安装了 pytest 包。


## 测试驱动开发建议

单元测试不仅仅用于验证已有代码，更是测试驱动开发（TDD）的核心实践。

推荐的开发流程是先编写测试用例，再编写实现代码，最后通过测试验证。

养成编写测试的习惯，你的代码质量将得到显著提升。
