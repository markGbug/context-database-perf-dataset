## 本章内容

引用块用于突出显示重要信息、引用他人观点或创建视觉层次。


### 单级引用的使用

基本语法：

Markdown 区块引用是在段落开头使用 > 符号 ，然后后面紧跟一个空格符号：

```text
> 区块引用
> 菜鸟教程
> 学的不仅是技术更是梦想
```

显示结果如下：

多行引用：

```text
> 这是引用的第一行。
> 这是引用的第二行。
>
> 这是引用的第二段。
```

简化写法：

只在第一行使用 > ，其余行会自动包含在引用中：

```text
> 这是一个长引用，
包含多行内容，
只需要在第一行使用 > 符号。
```


### 多级嵌套引用

另外区块是可以嵌套的，一个 > 符号是最外层，两个 > 符号是第一层嵌套，以此类推：

```text
> 最外层
> > 第一层嵌套
> > > 第二层嵌套
```

显示结果如下：

实际应用示例：

```text
> **用户反馈**：这个功能很有用！
>
> > **开发团队回复**：感谢您的反馈，我们会继续优化。
> >
> > > **项目经理补充**：预计下个版本会有更多改进。
```

### 列表中使用区块

如果要在列表项目内放进区块，那么就需要在 > 前添加四个空格的缩进。

列表中使用区块实例如下：

```text
* 第一项
    > 菜鸟教程

## 引用块内的其他元素

引用块内可以包含几乎所有其他 Markdown 元素。

包含标题：

```text
> ## 重要提醒
>
> 请在操作前仔细阅读文档，避免数据丢失。
```

包含列表：

```text
> ### 注意事项
>
> 1. 备份重要数据
> 2. 检查系统兼容性
> 3. 准备回滚方案
>
> - 测试环境验证
> - 生产环境部署
> - 监控系统状态
```

包含代码：

```text
> 要运行这个脚本，请使用以下命令：
>
> ```bash
> npm install
> npm start
> ```
>
> 执行后会在 `http://localhost:3000` 看到结果。
```

包含链接和图片：

```text
> 📚 **推荐阅读**
>
> 详细信息请参考 [官方文档](https://example.com)
>
> ![示例图片](./images/example.png)
```

### 重要信息提示

成功提示：

```text
> ✅ **成功**
>
> 配置已保存并生效。系统将在下次重启时应用新设置。
```

警告信息：

```text
> ⚠️ **警告**
>
> 此操作不可逆转，请确保已备份重要数据。
```

错误信息：

```text
> ❌ **错误**
>
> 连接数据库失败，请检查网络连接或联系系统管理员。
```

信息提示：

```text
> ℹ️ **提示**
>
> 首次使用需要进行账户验证，验证邮件已发送到您的邮箱。
```
