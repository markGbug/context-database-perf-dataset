## 本章内容

Eclipse 查看的菜单栏通常包含以下几个菜单：

- File 菜单
- Edit 菜单
- Navigate 菜单
- Search 菜单
- Project 菜单
- Run 菜单
- Window 菜单
- Help 菜单

通过 Eclipse 插件你可以添加新的菜单和菜单项。
