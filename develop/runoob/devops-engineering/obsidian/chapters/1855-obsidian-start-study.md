### 什么是 Obsidian？

Obsidian 本质上是一个**强大的笔记应用**，但它不仅仅是记录文字。它是一种将你的笔记、想法和知识点连接起来的工具，旨在构建一个**网状的、可搜索的、私人的知识网络**，就像你大脑中的神经元连接一样。

* **本地文件存储：** Obsidian 的所有文件都以纯文本的 **Markdown** 格式存储在你的本地电脑上。这意味着：
 * **安全可控：** 你的数据完全属于你自己，不需要依赖任何云服务商。
 * **永不过时：** Markdown 是最通用的纯文本格式，即使 Obsidian 停止服务，你仍然可以用任何文本编辑器打开你的笔记。

### 为什么要用 Obsidian？（核心优势）

你可能用过 Word、Evernote 或 Notion，为什么还要选择 Obsidian？

| :--- | :--- | :--- |

| **纯文本与开放生态** | 基于 Markdown 和本地文件。 | 跨平台兼容性强，未来可导出性高，方便配合其他工具使用。 |
| **高度可定制** | 拥有数千个社区插件和主题。 | 无论是学生、程序员还是作家，你都可以根据需求定制功能和外观。 |

## Vault 的目录结构

当你创建一个 Vault 后，文件夹里会出现一个隐藏目录 .obsidian：

```text
MyVault/
├── .obsidian/           ← Obsidian 的配置文件
│   ├── plugins/         ← 安装的插件存放在这里
│   ├── themes/          ← 主题文件
│   ├── snippets/        ← 自定义 CSS 片段
│   └── app.json         ← 主配置文件
├── 你的第一篇笔记.md
└── ...
```

给开发者的提示：.obsidian 文件夹推荐纳入 Git 管理。这样你的插件配置、快捷键设置、主题偏好都会被版本控制，换电脑时可以完整恢复。唯一的例外是 .obsidian/workspace.json，它记录了当前打开的标签页状态，可以加入 .gitignore。

## 适用场景与使用边界

Obsidian 很强大，但它不是万能的。了解它的适用边界，帮助你做出合理的工具选择。


### Obsidian 擅长的事

- 技术知识积累：记录某个框架的理解、踩坑经历、解决方案，通过链接把相关知识串联起来
- 学习笔记：阅读书籍/文章时做摘录和批注，沉淀为自己的知识
- 每日工作日志：用 Daily Notes 记录每天做了什么、遇到了什么问题
- 写作草稿：在 Obsidian 中积累素材、打磨文章
- 个人项目规划：追踪个人学习计划、副业项目


### Obsidian 不太擅长的事

- 团队实时协作：多人同时编辑同一文件容易产生冲突，Notion 更合适
- 结构化数据管理：复杂的数据库、电子表格，用 Notion/Airtable
- 任务管理主力工具：虽然有插件支持，但专业的任务管理建议用 Todoist/Linear
- 大型多媒体内容：视频、大量图片等，存储和管理不方便
