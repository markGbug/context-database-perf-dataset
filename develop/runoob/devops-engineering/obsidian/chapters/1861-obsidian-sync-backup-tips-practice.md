## 本章内容

笔记系统最重要的是数据安全——你花了大量时间积累的知识不能因为硬盘损坏或误操作而丢失。

本章覆盖同步方案、备份策略、移动端使用和常见问题排查。


## 官方同步：Obsidian Sync

Obsidian Sync 是官方提供的端对端加密云同步服务，是体验最好的同步方案。


### 核心特性

- 端对端加密：数据在上传前已在本地加密，服务商无法读取你的笔记内容
- 增量同步：只同步变化的部分，速度远快于全量复制
- 版本历史：保存每个文件的修改历史，可回溯到任意版本
- 多设备同步：桌面端、移动端无缝同步，冲突自动合并


### 价格

Obsidian Sync 是付费服务，按年订阅。

如果你有 5 个以上的 Vault 或笔记库体积较大，Sync 是最省心的选择。


### 配置步骤

- 在设置 → 同步（Sync）中登录 Obsidian 账户
- 选择一个远程 Vault（首次需创建）
- 设置加密密码（务必妥善保管，丢失后无法恢复）
- 选择要同步的文件夹和文件类型
- 在另一台设备上同样登录并连接到同一个远程 Vault

加密密码是恢复数据的唯一凭证。官方无法帮你重置。建议将密码保存在密码管理器中，或写在纸上安全存放。


## 免费同步方案

如果你不想为同步付费，有几种免费方案可以选择。


### iCloud（macOS + iOS 用户首选）

将 Vault 文件夹放在 iCloud Drive 中，macOS 和 iOS 设备间自动同步。

优点是零配置、苹果生态无缝体验。

缺点是 Windows 上的 iCloud 客户端体验一般，偶尔出现同步冲突。


### OneDrive / Dropbox

将 Vault 文件夹放在 OneDrive 或 Dropbox 的同步目录中。

支持全平台（Windows、macOS、Linux、移动端），比 iCloud 跨平台兼容性更好。

注意：不要在多个设备上同时编辑同一篇笔记，可能产生冲突副本。


### Git + GitHub 版本管理

将 Vault 初始化为 Git 仓库，推送到 GitHub 私有仓库。

这种方法的好处是自带版本历史，每次提交都相当于一个快照。


## 实例：初始化 Vault 为 Git 仓库

在移动端可以通过 Working Copy（iOS）或 MGit（Android）等 Git 客户端拉取和推送。

Git 同步需要手动 commit + push + pull，不能像 iCloud 那样自动同步。适合有 Git 使用习惯的用户，或者作为其他同步方案的补充（额外增加一层版本保护）。

## 移动端使用

Obsidian 提供 iOS 和 Android 客户端，功能与桌面端基本一致。


### 移动端特色功能

- 快速笔记：iOS 的快捷指令和 Android 的快速磁贴，一键创建笔记
- 语音备忘录：部分社区插件支持语音转文字
- 下拉手势：在文件列表顶部下拉刷新同步状态


### 移动端技巧

移动端更适合捕获而非整理。

建议在手机上只做两件事：快速记录灵感和任务（通过快捷方式打开日记），以及随时查阅已有笔记。

复杂的排版、模板应用、Dataview 查询编写等操作留到桌面端完成。


### 移动端工具栏配置

在移动端设置中可以自定义编辑工具栏，把常用的 Markdown 操作（加粗、链接、图片、复选框）放在最容易点到的位置。


## 导出与发布


### 导出 PDF

打开笔记，点击右上角「更多选项 → 导出 PDF」。

导出的 PDF 会保留当前的 Obsidian 主题样式。


### Pandoc 导出（更灵活的格式转换）

安装 Pandoc 社区插件后，可以将笔记导出为 Word、HTML、LaTeX 等多种格式。

需要先在系统中安装 Pandoc 命令行工具。

```text
# macOS 安装 Pandoc
$ brew install pandoc

# Windows 安装 Pandoc（在 PowerShell 中）
$ winget install --id JohnMacFarlane.Pandoc
```


### Obsidian Publish：建立个人数字花园

Obsidian Publish 是官方付费服务，可以将选定的笔记发布为网站。

发布的网站保留双链、图谱、搜索等 Obsidian 核心功能。

适合用来搭建个人博客、公开知识库或项目文档站。


## 数据备份策略

同步不等于备份——同步会把你误删的文件也同步删除。

好的备份策略应该考虑3-2-1 原则：3 份副本，2 种介质，1 份异地。

### 纯文本的长期可靠性

Obsidian 笔记全部是纯文本 Markdown 文件。

30 年后，你仍然可以用任何文本编辑器打开它们。

这是 Obsidian 相比所有专有格式笔记软件最重要的长期优势——你的笔记的寿命，不取决于任何公司的存亡。


## 常见问题排查


### 插件冲突排查

如果你遇到启动缓慢、界面异常、操作卡顿等问题，很可能是插件冲突。

排查方法：

- 在设置中关闭所有社区插件
- 逐个重新启用，每次启用后测试问题是否复现
- 找到引发问题的插件后，检查是否有更新或已知 bug

使用命令 Cmd+Shift+I（Windows: Ctrl+Shift+I）可以打开开发者工具，在 Console 面板中查看具体报错信息。
