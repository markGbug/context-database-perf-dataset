## Beamer：学术幻灯片标准工具

Beamer 是 LaTeX 的幻灯片文档类，也是数学、计算机领域学术报告的主流工具——它排出的公式幻灯片，是 PPT 很难企及的。

核心概念只有一个：frame（帧）。一个 frame 就是一页幻灯片，其余语法与你学了十一篇的 LaTeX 完全一致。

主题是 Beamer 的换装开关：Madrid 庄重、Boadilla 紧凑、Berlin 分栏导航，都改一个词就能换。学术报告选 Madrid 或 default 不会出错。

Beamer 的强项是「公式 + 条目 + 图表」的学术报告；如果演示以图形动画、多媒体为主，用 PPT 或 Keynote 更合适，不必勉强。


## 简历：moderncv 模板

简历是最能体现「内容与样式分离」的场景：模板负责好看，你只负责填内容。


## 实例：moderncv 中文简历

三套命令记住就够用：\cventry 排「时间 + 职位 + 单位」的经历条目，\cvitem 排「标签 + 内容」的技能行，\section 生成蓝色分组标题。

moderncv 之外，中英文简历还可以关注 Awesome-CV、Deedy-Resume 等开源模板（GitHub 可搜到），都是「填内容即可出片」的成熟方案。
