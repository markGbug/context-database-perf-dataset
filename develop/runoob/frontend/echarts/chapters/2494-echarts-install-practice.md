## 1、独立版本

我们可以在直接下载 echarts.min.js 并用 <script> 标签引入。

echarts.min.js(4.7.0)

另外，开发环境下可以使用源代码版本 echarts.js 并用 <script> 标签引入，源码版本包含了常见的错误提示和警告。
