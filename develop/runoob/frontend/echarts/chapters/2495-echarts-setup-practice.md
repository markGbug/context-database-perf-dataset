### 第一步：创建 HTML 页面

创建一个 HTML 页面，引入 echarts.min.js：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <!-- 引入 ECharts 文件 -->
    <script src="echarts.min.js"></script>
</head>
</html>
```
