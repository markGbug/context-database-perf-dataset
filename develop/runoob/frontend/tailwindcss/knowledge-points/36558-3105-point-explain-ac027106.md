## 原文片段

Tailwind CSS 的核心理念是 工具优先（Utility-First）。通过组合一系列低级的工具类，你可以非常精确地控制元素的样式。虽然这种方式在初期很强大，但随着项目越来越复杂，尤其是在处理常见的 UI 元素（如按钮、卡片、头像等）时，往往会在多个地方重复使用相同的工具类。
