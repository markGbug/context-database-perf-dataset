## 原文片段

我们在 <ol> 或 <ul> 元素上添加 data-joyride 属性和 .joyride-list 类来创建 joyride。你需要在文档头部定义它 (在 <body> 内的头部)。在每个列表上使用 <li> 元素，每个元素添加 data-id="value" 属性。属性的 value 必须与之前元素的 id 相同。
