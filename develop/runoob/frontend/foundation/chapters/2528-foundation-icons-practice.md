## 图标语法

创建图标语法格式如下:

```html
<i class="fi-name"></i>
```

name 部分替换为图标的名字。

要使用图标我们需要在 <head> 部分添加图标的样式文件：

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/foundation-icons@2.0.0/foundation-icons.min.css">
```
