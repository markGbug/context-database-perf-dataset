## Foundation 图标

Foundation 提供了 283 图标，你可以使用 CSS 来渲染她们：修改大小和颜色。

图标创建语法格式如下：

```html
<i class="fi-name"></i>
```

语法中 name 部分为图标指定的名称。

要使用图标，你可以将图片的样式文件放置在页面头部 <head> 部分:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/foundation-icons@2.0.0/foundation-icons.min.css">
```

以上是菜鸟教程使用的图标样式类，大家可以共用。
