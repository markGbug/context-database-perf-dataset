## 本章内容

在学习本章节内容前，你需要先了解什么是异步编程，可以参考：JavaScript 异步编程

Promise 是一个 ECMAScript 6 提供的类，目的是更加优雅地书写复杂的异步任务。

Promise 是 JavaScript 中用于处理异步操作的对象，它代表一个异步操作的最终完成（或失败）及其结果值。
