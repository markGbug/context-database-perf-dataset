### 小结

- if 语句：适合在 render 方法或函数组件的返回值中使用来决定渲染内容。
- 三元运算符：适合在 JSX 中进行简洁的条件渲染。
- 逻辑与 (&&) 运算符：适合在 JSX 中条件渲染，当条件为 true 时渲染元素。
- switch 语句：适合处理多个条件，进行不同内容的渲染。
