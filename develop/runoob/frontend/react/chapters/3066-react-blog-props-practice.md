## 本章内容

组件化是 React 最核心的设计思想。本章你将学会把页面拆成可复用的小组件，通过 Props 和回调函数实现父子通信。


## 为什么要拆组件？

App.jsx 写得越来越长，上百行代码挤在一起，难以维护和复用。

拆组件的原则：每个组件只负责一件事，组合起来完成复杂功能。
