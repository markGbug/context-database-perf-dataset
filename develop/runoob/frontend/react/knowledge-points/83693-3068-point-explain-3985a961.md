## 原文片段

省略依赖数组 vs 空数组的区别：useEffect(fn) 每次渲染后都执行；useEffect(fn, []) 只在首次渲染后执行一次。前者极易造成死循环（effect 中 setState → 触发渲染 → 再执行 effect → ...），几乎从来不用。
