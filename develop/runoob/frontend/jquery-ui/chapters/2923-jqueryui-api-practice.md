## 本章内容

jQuery UI 是建立在 jQuery JavaScript 库上的一组用户界面交互、特效、小部件及主题。

如果您是 jQuery 新手，您可以先查看 jQuery 教程。

本教程提供了 jQuery UI 1.10 API 文档。如果您使用的是旧版本，我们建议您更新到 jQuery UI 1.10，以便获取最好的支持，充分利用最新的 bug 修复和增强功能。如需了解更多有关 jQuery UI 1.10 的信息，请访问 发布公告 和 升级指南。

jQuery UI 1.10 支持 jQuery 1.6 及以上的版本。
