## HTML 标题

HTML 标题（Heading）是通过<h1> - <h6> 标签来定义的。


## 实例

```html
<h1>这是一个标题</h1>
<h2>这是一个标题</h2>
<h3>这是一个标题</h3>
```


## HTML 段落

HTML 段落是通过标签 <p> 来定义的。


## 实例

```html
<p>这是一个段落。</p>
<p>这是另外一个段落。</p>
```


## HTML 链接

HTML 链接是通过标签 <a> 来定义的。


## 实例

```html
<a href="https://www.runoob.com">这是一个链接</a>
```

提示:在 href 属性中指定链接的地址。

(您将在本教程稍后的章节中学习更多有关属性的知识)。


## HTML 图像

HTML 图像是通过标签 <img> 来定义的.


## 实例

```html
<img src="/images/logo.png" width="258" height="39" />
```

注意： 图像的名称和尺寸是以属性的形式提供的。
