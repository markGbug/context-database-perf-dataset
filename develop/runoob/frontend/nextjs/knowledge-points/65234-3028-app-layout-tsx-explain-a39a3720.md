## 原文片段

注意事项：全局样式可以导入到 app 目录中的任何布局、页面或组件中。然而，由于 Next.js 使用 React 的内置样式表支持来与 Suspense 集成，当前的内置支持在你在路由之间导航时并不会移除样式表。因此，我们建议将 全局样式 用于真正的全局 CSS，而将 CSS 模块 用于作用域 CSS。
