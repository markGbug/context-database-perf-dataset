## 原文片段

drop 命令删除数据库 drop 命令格式： DROP DATABASE <database_name>; -- 直接删除数据库，不检查是否存在 或 DROP DATABASE [IF EXISTS] <database_name>; 参数说明： IF EXISTS 是一个可选的子句，表示如果数据库存在才执行删除操作，避免因为数据库不存在而引发错误。database_name 是你要删除的数据库的名称。
