## 原文片段

SELECT column1, column2, columnN：这部分指定了要从数据库中选择哪些列。column1、column2 和 columnN 是列的名称，你可以替换成实际的列名。columnN 表示可能还有更多的列，这里用 N 表示列的数量是可变的。
