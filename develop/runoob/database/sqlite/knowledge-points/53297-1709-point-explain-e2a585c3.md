## 原文片段

以上 SQL 语句从 table_name 表中选择column1、column2等列的数据，并且限制返回的行数和起始行，通常用于分页显示数据，其中LIMIT用于控制每页显示的行数，OFFSET用于控制从哪一行开始显示数据。
