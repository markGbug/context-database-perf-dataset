## 原文片段

数据源形式如下所示：DBI:SQLite:dbname='test.db'。其中，SQLite 是 SQLite 驱动程序名称，test.db 是 SQLite 数据库文件的名称。如果文件名 filename 赋值为 ':memory:'，那么它将会在 RAM 中创建一个内存数据库，这只会在 session 的有效时间内持续。
