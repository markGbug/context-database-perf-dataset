## 本章内容

SQLite 的一个重要的特性是零配置的，这意味着不需要复杂的安装或管理。本章将讲解 Windows、Linux 和 Mac OS X 上的安装设置。


## 在 Windows 上安装 SQLite

- 请访问 SQLite 下载页面，从 Windows 区下载预编译的二进制文件。
- 您需要下载 sqlite-tools-win32-*.zip 和 sqlite-dll-win32-*.zip 压缩文件。
