## 原文片段

例如，在 Ubuntu 上可以使用 apt 包管理器： 为 Ubuntu 22.04 (Jammy) 创建 /etc/apt/sources.list.d/mongodb-org-7.0.list 文件： echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list sudo apt update sudo apt install mongodb-shell 安装完成后，MongoDB Shell 将可以在命令行中通过 mongosh 命令启动。
