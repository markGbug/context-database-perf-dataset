## 原文片段

另一种方法是从 MongoDB 官网下载适用于 macOS 的 MongoDB Shell，下载地址 https://www.mongodb.com/try/download/shell : 下载后，解压安装包，将 bin 目录中 mongosh 二进制文件复制到 PATH 变量中列出的目录中，例如 /usr/local/bin： sudo cp mongosh /usr/local/bin/ sudo cp mongosh_crypt_v1.so /usr/local/lib/ 安装完成后，MongoDB Shell 将可以在命令行中通过 mongosh 命令启动。
