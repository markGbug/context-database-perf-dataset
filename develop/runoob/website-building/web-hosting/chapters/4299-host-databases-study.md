## 本章内容

MS SQL Server 或者 Oracle 用于高流量的数据库驱动型网站。

MySQL用于低成本的数据库访问。

MS Access 用于低流量的网站。


## 网站数据库

如果您的网站需要经由 web 来更新大量的信息，那么您就需要数据库来存储信息。

可用于网站主机的数据库系统有很多种类型。最常见的是 MS Access、MySQL、SQL Server 以及 Oracle。
