## Web 网页验证器

验证器是一种软件程序，可以检查对Web网页是否标准。

当使用验证器来检查HTML,XHTML或CSS文件时，验证器会根据您所选择的标准返回一个错误列表。

在发布网页之前请确保你验证过所有的网页都符合W3C标准。

## 动手验证

- 跟着本章示例重新输入一遍，不要只复制粘贴 `网站验证` 的代码。
- 修改一个条件、参数或输入值，观察输出是否符合预期。
- 记录一次出错信息，并写下定位步骤和修复方式。
- 用自己的话解释示例为什么会得到当前输出。
