## 本章内容

jQuery Mobile 是用于创建移动 Web 应用的前端开发框架。

jQuery Mobile 可以应用于智能手机与平板电脑。

jQuery Mobile 使用 HTML5 & CSS3 最小的脚本来布局网页。

```html

  <div data-role="header">

  <div data-role="content">
    <p>页面内容</p>
  </div>

  <div data-role="footer">

  </div>
</div>
```
