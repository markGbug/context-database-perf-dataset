## 本章内容

Swift 是 Apple 于 2014 年发布的一门通用编程语言，主要用来开发 iOS、iPadOS、macOS、watchOS、tvOS 应用，2015 年开源后交给 Swift 社区与 Apple 共同维护，编译器、标准库、包管理器的源码都可以在 GitHub 上找到。

Swift 把 C 与 Objective-C 的优点结合在一起，同时摆脱了 C 兼容性带来的历史包袱，与 Objective-C 相比，Swift 语法更简洁，并且把空值安全、类型安全、内存管理这些容易出错的地方交给编译器在编译期检查。

Swift 是一门编译型语言，源码先由 Swift 编译器编译成机器码，再直接运行，不需要虚拟机。

Swift 同时支持面向过程、面向对象、函数式和面向协议四种编程范式。

注意：Swift 的语法在 Swift 3 有过一次大改，网上的老教程如果还在用 println、++、C 风格 for 循环，基本都是 Swift 2 时代的写法，已经无法编译。

## 为什么选择 Swift

选择一门语言，通常看四点：安全、性能、表达力和生态，Swift 在这四点上的表现都比较均衡。

安全 是 Swift 最强调的设计目标。

可选类型 Optional 强制你在使用一个可能为空的值之前先处理空值，从语言层面消灭了「空指针解引用」这类崩溃。

类型安全让不同类型之间不会隐式转换，例如 Int 和 Double 必须显式转换才能运算，编译期就能发现类型错误。

整数溢出默认会直接终止程序而不是静默回绕，这避免了大量难以排查的数值 bug。

快速 是第二个优势。

Swift 编译器使用 LLVM 后端，会做大量内联、泛型特化和内存优化，性能接近 C 语言，远高于脚本语言。

字符串、数组、字典等基础类型都用结构体实现，配合写时复制（COW）机制，既有值语义的安全性，又有引用语义的效率。

表达力 让代码更接近自然语言。

字符串插值、闭包简写、协议扩展、属性包装器等特性，让很多在其他语言里需要写几十行的逻辑，在 Swift 里几行就能表达清楚。

跨平台 是 Swift 从 2015 年开源后逐步补齐的能力。

Swift 现在可以在 macOS、Linux、Windows 上编译运行，也支持服务器端开发和嵌入式设备。
