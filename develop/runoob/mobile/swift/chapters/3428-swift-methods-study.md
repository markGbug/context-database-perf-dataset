## 本章内容

方法是与某个特定类型（类、结构体或枚举）关联的函数，用来描述这个类型能做什么。

它与普通函数最大的区别是：方法要通过某个实例或类型来调用，并且可以直接访问该实例的属性。


## 实例方法

实例方法属于某个具体实例，可以读取和修改该实例的属性，也可以调用同类型的其他方法。

## 方法的参数标签规则

这是 Swift 初学者最容易写错的地方，必须先把规则记牢。

从 Swift 3 开始（SE-0046），所有参数默认都带外部标签，第一个参数也不例外。也就是说，func greet(site: String) 调用时要写成 greet(site: "RUNOOB")。

想让外部标签与参数名不同，写成 func f(label name: Type)；想省略标签，用下划线 _ 显式省略。

## self 属性

每个实例都有一个隐含属性 self，它完全等同于实例本身。

当参数名与属性名相同时，用 self 明确指代属性，避免把赋值写成参数自己赋给自己。


## 实例

运行结果：

```text
a 在 b 的右侧：true
b 在 a 的右侧：false
```

实例方法里访问自身属性时，通常可以省略 self，Swift 会自动推断；只有在需要消除歧义时才必须写出来。


## mutating 方法与 self 赋值

结构体和枚举是值类型，默认情况下实例方法不能修改自身的属性。

要让方法能修改属性，需要在 func 前加 mutating 关键字。

mutating 方法还有一个更强能力：可以把整个 self 替换成一个全新的实例。


## 实例

运行结果：

```text
递增后：2
翻倍后：4
重置后：0
```

注意：mutating 方法只能用 var 声明的实例调用。用 let 声明的结构体实例，即使属性是变量也不能调用 mutating 方法。


## 类型方法

类型方法属于类型本身，不需要创建实例就能调用，用点号语法访问。

结构体和枚举的类型方法用 static 声明；类中可以用 class 声明可被子类重写的类型方法。


## 实例

运行结果：

```text
35
这是一个形状
这是一个圆
二维图形
```

区分两者的关键：static 定义的类型成员不能被重写，class 只能用于类，且允许子类用 override 重写。

注意：存储型的类型属性必须用 static 声明，class 只用于可重写的计算型类型属性或类型方法。


## @discardableResult

如果方法的返回值在调用时经常被忽略，可以加上 @discardableResult，这样忽略返回值时编译器不会给出警告。


## 实例

运行结果：

```text
余额：120
```

这个标记只是关闭警告，并不会改变方法的实际行为，返回值依然可以正常使用。


## 常见问题

下面几个问题在写方法时出现频率最高。


### 调用时提示 argument labels 不匹配

多半是标签写错了。先看定义里参数有没有外部标签：有 _ 就不写，写成 label name 就写 label，什么都不写就写参数名本身。


### 结构体方法里改属性报错

实例方法默认不能修改值类型的属性，给方法加上 mutating 即可。如果实例是用 let 声明的，还要改成 var。


### 类型方法里访问实例属性报错

类型方法没有实例上下文，不能直接访问实例属性。要么把方法改成实例方法，要么把数据也做成类型属性。
