## 本章内容

闭包是一段可以像值一样传递和使用的代码块，它能捕获并保存定义处周围的变量。

在 Swift 里，全局函数、嵌套函数和闭包表达式本质上都是闭包，区别只在于写法与命名。

本文讲解闭包表达式的简化过程、尾随闭包、捕获机制，以及逃逸与非逃逸这两个容易出错的概念。


## 闭包的三种形式

Swift 官方把闭包分成三种形式，它们的能力一致，只是形态不同。

完整形式是 { (参数) -> 返回类型 in 语句 }。

尾随闭包能省掉一层括号，让代码更接近「配置块」的阅读体验。

## 捕获列表 [weak self] 与 [unowned self]

在类中把闭包存进属性时，闭包会强引用 self，容易形成循环引用。

捕获列表写在参数列表之前，用来指定捕获方式，从而打破这个环。


### [weak self]

weak 是弱引用，对象释放后自动变成 nil，因此访问时要先解包。

### [unowned self]

unowned 也是不增加引用计数，但它假设对象一定还活着，访问时不需要解包。

一旦对象已经释放却仍然访问，程序会直接崩溃，所以它只适合生命周期确定不会错开的关系。

```text
2
```

注意：拿不准用哪个时，选 [weak self] 并配合 guard let self else { return }。它更安全，代价只是一次可选值解包。


## 逃逸闭包与非逃逸闭包

函数类型参数默认是非逃逸的：闭包保证在函数返回前执行完。

需要保存下来、在函数返回之后才调用的闭包，必须标注 @escaping。
