## 本章内容

数组（Array）用来按顺序存放同一类型的多个元素，是 Swift 中最常用的集合类型。

它保留了元素的插入顺序，可以按下标随机访问，也能动态地追加和删除元素。

本篇讲数组的创建、下标访问、增删改、三种遍历写法，以及 Swift 数组最重要的特性之一：值语义与写时复制。

键值对集合请见《Swift 字典》，无序集合与高阶函数请见《Set 与高阶函数》。

## 访问元素与下标

用下标访问元素，下标从 0 开始，范围是 0 到 count - 1。

下标越界会直接触发运行时陷阱，程序终止，不会像可选值那样返回 nil。

想安全取值，用 first 和 last，它们返回的是可选值。


## 实例

以上代码执行输出结果为：

```text
Runoob
Runoob
www.runoob.com
3 false
1
true
false
```

indices 是数组的有效下标范围，先用 contains(_:) 判断再取值，可以避免越界崩溃。

上例中数组只有 3 个元素，合法下标是 0、1、2，所以 indices.contains(3) 为 false。

## 遍历数组

用 for-in 可以逐个取出元素，这是最常用的写法。

需要下标时，配合 enumerated() 拿到「下标 + 元素」的元组，或者直接遍历 indices。


## 实例

以上代码执行输出结果为：

```text
Runoob
RUNOOB
www.runoob.com
0: Runoob
1: RUNOOB
2: www.runoob.com
0 -> Runoob
1 -> RUNOOB
2 -> www.runoob.com
```

注意：enumerate() 是 Swift 2 的旧写法，Swift 3 起改名为 enumerated()。另外，遍历期间不要增删元素，这会让遍历行为变得不可预期，需要过滤或删除时先用 filter 生成一个新数组。


## 值语义与写时复制

把数组赋给另一个变量，或者作为参数传给函数，得到的是独立的副本。

修改其中一个，另一个不受影响。


## 实例

以上代码执行输出结果为：

```text
a = [1, 2, 3], b = [1, 2, 3, 4]
```

Swift 并不会在赋值时立刻复制整份数据，而是先共享同一块存储，只在引用计数上加一。

当其中一方要写入，且发现这块存储还被别人引用时，才真正复制出独立的一份，这套机制叫写时复制（Copy-On-Write，COW）。

它既保证了值语义，又避免了大数组在传参时被反复拷贝，性能与语义两头都不吃亏。

原理详见《Swift 值语义与写时复制》。

注意：结构体里如果嵌套了引用类型，值语义会被打破。修改副本中的引用对象，原对象也会看到变化，这类情况需要自己实现深拷贝。


## 常见问题

下面是数组使用中最常见的几个问题。


### 数组是值类型还是引用类型

是值类型。赋值时语义上等同于复制，实际由写时复制优化，只有真正写入才产生副本。

这一点与 Objective-C 中共享同一个对象的 NSArray 完全不同。


### 下标越界会怎样

会触发运行时陷阱，程序直接终止，不会静默返回 nil，也没有「越界返回默认值」的行为。

不确定下标是否合法时，先用 indices.contains(index) 判断，或改用 first、last 这类返回可选值的属性。


### repeating 和 count 参数顺序记不清怎么办

记住「先说什么值、再说几个」，也就是 [Int](repeating: 0, count: 3)。

写反成 [Int](count: 3, repeating: 0) 会直接编译报错，编译器会提示没有匹配的初始化器。


### 怎么快速找出某个元素的下标

用 firstIndex(of:)，它返回 Int?，元素不存在时是 nil。

只想判断存不存在，用 contains(_:) 更直接。
