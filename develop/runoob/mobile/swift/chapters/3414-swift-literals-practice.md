## 本章内容

字面量（literal）是直接写在源码里、一眼就能看出类型的值，例如 42、3.14、"Runoob" 和 true。

Swift 会根据字面量的写法和上下文推断类型，所以写代码时通常不需要额外标注。


## 什么是字面量

下面三行赋值，右侧都是字面量，左侧变量的类型由 Swift 自动推断出来。


## 实例

以上程序执行结果为：

```text
3 Runoob true
```

如果上下文无法推断，或者你想要更精确的类型，可以显式写类型标注，例如 let price: Double = 9.9。


## 整型字面量

整型字面量可以用十进制、二进制、八进制或十六进制书写，前三种写法最终得到的都是同一个 Int 值。

数字中间可以插入下划线 _ 方便阅读，下划线会被完全忽略，不影响数值。


## 实例

以上程序执行结果为：

```text
17 17 17 17
1000000 1234567890123456
```

注意：字面量本身没有固定的位宽，具体是 Int 还是 Int8 由上下文决定。上面的例子没有标注类型，Swift 统一推断为 Int。


## 浮点字面量

浮点字面量由整数部分、小数点、小数部分和指数部分组成，写法比整型多一些。

没有显式标注时，浮点字面量默认推断为 Double（64 位）。

十六进制浮点数的指数部分用字母 p（而不是 e），表示乘以 2 的多少次方。


## 实例

以上程序执行结果为：

```text
12.1875 12.1875 4.0 12.1875 1000000.0000001
```

负数只需要在前面加一元减号，例如 -42.5，它等价于对字面量 42.5 取负。


## 字符串字面量

字符串字面量由一对双引号包起来，里面可以放普通字符、转义序列和插值表达式。


## 实例

以上程序执行结果为：

```text
你好，www.runoob.com
```


### 转义序列

Swift 支持的转义序列不多，只有下面这几个；写错了编译器会直接报错。


## 实例

以上程序执行结果为：

```text
Hello    World
菜鸟教程："http://www.runoob.com"
反斜线：\ 单引号：'
han = 中，count = 1
```

注意：Swift 没有 C 语言里的 \b、\f、\v，也不支持八进制转义。写 "\b" 会得到 error: invalid escape sequence in literal。


### 多行字符串

用一对三引号 """ 可以写跨行的字符串，闭合三引号的缩进决定了每行被剥掉多少缩进。


## 实例

以上程序执行结果为：

```text
Runoob
www.runoob.com
长度：21
他说："欢迎来到 Runoob"
```


### 原始字符串

在三引号或双引号外面再加一个 #，就得到原始字符串：反斜线不再触发转义，\n 只是两个普通字符。

原始字符串里要做插值，需要在反斜线后再加一个 #，写成 \#(...)。


## 实例

以上程序执行结果为：

```text
目录 "C:\Users\Runoob" 里的 \n 不换行
插值仍然可用：17
```


## 布尔字面量

布尔字面量只有两个：true 和 false，它们的类型是 Bool。


## 实例

以上程序执行结果为：

```text
true false
isRunoob 的类型是 Bool
```

注意：nil 不是布尔字面量，它表示「没有值」，只能赋给可选类型。Swift 也没有「0、空字符串为假」这类隐式转换，条件位置必须放一个真正的 Bool，详见第 9 篇《Swift 条件语句》。


## 数组与字典字面量

数组字面量用方括号列出元素，字典字面量用「键: 值」的形式列出键值对。


## 实例

以上程序执行结果为：

```text
["Runoob", "RUNOOB", "菜鸟教程"]
元素个数：3
Runoob www.runoob.com 2
```

注意：字典是无序的，遍历同一个字典两次，打印出的键值对顺序可能不同，所以上面用具体的键取值，而不是直接打印整个字典。
