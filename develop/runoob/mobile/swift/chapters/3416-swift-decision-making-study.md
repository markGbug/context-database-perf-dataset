## 本章内容

条件语句根据一个或多个条件的真假，决定执行哪一段代码。

Swift 提供了 if、switch、guard 和三元运算符，它们的共同前提是条件必须是 Bool。

if 语句由一个布尔条件和一段代码块组成，条件为 true 时才执行代码块。

if 后面可以跟一个 else，条件为 false 时执行 else 分支。
