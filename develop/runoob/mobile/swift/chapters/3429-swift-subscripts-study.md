## 本章内容

下标（subscript）是访问集合、序列或自定义类型中元素的快捷方式，用方括号语法 实例[索引] 取值和赋值。

数组的 array[0]、字典的 dict["key"] 都是下标，你可以在自己的类、结构体或枚举里定义同样的语法。


## 下标语法与应用

定义下标用 subscript 关键字，写法介于实例方法和计算属性之间：有参数列表和返回类型，但没有名字。


## 实例

运行结果：

```text
3 的 6 倍是 18
```

需要同时支持读写时，写下标参数的完整形式，用 get 和 set 分别处理取值与赋值。


## 实例

set 中的新值默认叫 newValue，也可以写成 set(value) 自定义名字。

下标可以接收任意数量的参数，参数类型也不受限制，因此同一个类型可以提供多个下标实现，靠参数类型和个数来区分，这就是下标的重载。

## 只读下标简写

只提供 get 的下标是只读下标，此时可以省略 get 关键字和外面那层花括号，直接写返回语句。

注意：只读下标不能出现在赋值语句左边。对只读下标写 instance[0] = x 会编译报错。


## 类型下标 static subscript

和类型方法类似，下标也可以用 static 声明成类型下标，直接通过类型本身访问，不需要创建实例。


## 实例

运行结果：

```text
mars
true
```

类中的类型下标用 class 声明时允许子类重写，用 static 声明则不允许重写。


## 下标与 inout

下标表达式是一个可读可写的位置，因此可以直接作为 inout 参数传入函数，函数内部对参数的修改会写回原来的元素。


## 实例

运行结果：

```text
[1, 2, 6, 4, 5]
[5, 2, 6, 4, 1]
```

如果下标只有 get 没有 set，把它作为 inout 参数传入会编译报错，因为函数无法把修改写回去。


## 常见问题

下标用起来简单，但下面几个坑值得留意。


### 下标越界会直接崩溃

数组下标不做边界检查之外的补救，访问超出范围的索引会触发运行时错误。自定义下标时建议在内部先判断索引是否合法。


### 字典下标返回的是可选值

字典下标取值的结果是可选类型，键不存在时返回 nil，所以不能直接当普通值使用，需要解包。


### 下标不能有默认参数

下标可以有多个参数，但不支持给参数设置默认值，重载要靠参数类型和个数来区分。
