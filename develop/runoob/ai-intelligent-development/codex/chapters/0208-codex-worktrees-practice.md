## 什么是 Worktree？

Git Worktree 是 Git 的一个功能，允许你在同一个仓库中创建多个工作目录。Codex 对 Worktree 提供了原生支持。


### 使用场景

- 并行开发多个功能
- 保持主分支干净
- 同时进行开发和代码审查
