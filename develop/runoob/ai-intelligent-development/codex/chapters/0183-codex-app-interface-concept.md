## 本章内容

Codex App 是 OpenAI 推出的一个AI Agent 工作台，它和普通聊天机器人最大的区别在于：它不是只负责回答，而是开始真正执行。

比如：

- 读取本地项目
- 修改代码
- 浏览网页
- 运行终端命令
- 操作浏览器
- 调用 Git
- 使用插件
- 自动化执行任务

它本质上已经不是传统意义上的聊天 AI，而是：一个以 AI 为核心的桌面工作操作系统。

OpenAI 官方对它的定义是：A command center for agents（Agent 指挥中心）。

它支持：

- 多 Agent 并行工作
- Worktree 隔离项目
- 长时间任务执行
- 自动化工作流
- Skills 技能系统

### 右侧多功能区

Codex 的右侧区域可以理解成：AI 的工作结果展示区。

这里主要用来查看：

- Codex 做了什么

右侧区域常见功能:

Git Diff 是我们开发最常用的功能之一，它会显示：

- 哪些代码被新增
- 哪些代码被删除
- 哪些文件被修改

Codex 可以直接在右侧打开浏览器：

- 访问网页
- 测试前端页面
