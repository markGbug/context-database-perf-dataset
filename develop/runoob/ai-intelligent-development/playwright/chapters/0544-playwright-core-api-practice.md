## 本章内容

本附录列出 Playwright 核心类的常用 API，供快速查阅。


## Playwright 类

Playwright 是 Playwright Library 的入口对象。


## BrowserType 类

BrowserType 用于启动和连接到浏览器。


## Browser 类

Browser 代表一个浏览器实例。


## BrowserContext 类

BrowserContext 代表一个独立的浏览器上下文。


## BrowserServer 类

BrowserServer 代表通过 launchServer() 启动的浏览器进程。
