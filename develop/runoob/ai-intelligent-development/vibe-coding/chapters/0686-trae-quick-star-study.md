## 本章内容

TRAE 是字节跳动推出的 AI 原生编程产品，将集成开发环境（IDE）与 AI 助手结合起来，帮助开发者理解项目、编写代码、排查问题和完成开发任务。

IDE 可以理解为程序员的工作台：编辑器用来写代码，终端用来运行命令，调试工具用来定位问题，版本控制用来管理修改。TRAE 在这些工具的基础上加入 AI，让我们可以直接用自然语言描述需求，再查看生成的代码和运行结果。

例如，我们可以输入"解释这个函数的作用"，也可以提出"为当前网页增加搜索功能"。学习代码时，可以边问边看；实现功能时，可以让智能体协助拆解任务、修改文件，再由我们检查结果。


## TRAE 的主要特点

- 中文界面与中文交互：支持使用中文描述需求，方便初学者理解操作和阅读回复。
- AI 问答与自动编程：既能解释代码、分析报错，也能结合项目文件协助实现功能。
- IDE / SOLO 双模式：可以在代码编辑界面中逐步操作，也可以围绕任务让 AI 规划和执行；另有 Agent 窗口用于集中管理任务。
- CUE 智能代码补全：在编写代码时提供补全与修改建议，减少重复输入。
- 延续熟悉的开发工具：支持 VS Code 扩展，并提供从 VS Code 或 Cursor 导入配置的入口，迁移后仍需检查所需扩展是否正常可用。
- 多模型选择：支持内置模型与自定义模型，可以按任务需要切换，或配置自己的 API Key。
- 多平台支持：桌面端提供 Windows、macOS 和 Linux 版本，按系统及芯片架构选择安装包。


## TRAE 适合做什么？


## 一、下载、安装并登录 TRAE

本节以 macOS 版 TRAE CN 为例。

先访问 TRAE 官网，按操作系统与芯片类型下载安装包。

Mac 用户可在苹果菜单的关于本机中查看芯片类型：Apple 芯片选择 Apple Silicon 版本，Intel 处理器选择 Intel 版本，Windows 用户请在官网下载入口选择 Windows 安装包。


### 1、把 TRAE 拖入"应用程序"

下载完成后，双击打开 .dmg 安装文件。在出现的窗口中，按住左侧 TRAE CN 图标，将它拖到右侧的 Applications 文件夹。

Applications 就是 Mac 的"应用程序"目录。等待复制完成，再从"应用程序"中打开 TRAE CN。


### 2、点击登录，选择个人用户

启动 TRAE 后，若出现主题、语言或配置导入引导，按需要完成设置。进入主界面后，点击右侧绿色的 "登录" 按钮，也可以使用窗口右上角的登录入口。

弹出身份选择窗口后，个人学习或日常开发选择 "个人用户"。只有使用企业分配的账号时，才选择"企业用户"。


### 3、使用手机号完成登录

在打开的登录页面中，依次完成：

- 输入自己的手机号码。
- 点击 "获取验证码"，填写收到的短信验证码。
- 阅读服务条款和隐私协议，同意后勾选确认。
- 点击 "登录"。

也可以选择图中的抖音或苹果登录入口，按相应页面完成授权。


### 4、确认登录并返回客户端

出现 "登录以使用 TRAE" 页面后，点击绿色的 "登录并打开 TRAE" 按钮。

如果浏览器询问是否打开 TRAE 应用，确认打开。若需要换一个账号，点击"使用其他账号登录"，重新完成登录流程。

返回客户端后，检查右上角是否已显示账号头像。如果浏览器没有自动切回，可以手动打开 TRAE 查看登录状态。


## 二、发送第一条消息


### 5、在右侧输入框中开始对话

登录后，先不用创建复杂项目。在右侧面板底部输入一句简单的问题，点击右下角的 向上箭头按钮 发送：

```text
你好，我是编程初学者。请介绍一下你能帮我完成哪些开发任务，并用简单的例子解释 HTML、CSS 和 JavaScript 的作用。
```

收到回复后，可以继续追问，例如"再举一个网页按钮的例子"。图中左侧是更新日志，不是必须填写的页面；当前操作主要在右侧对话区完成。


## 三、选择模型与添加自定义模型


### 6、从 Auto 入口选择模型

点击对话输入框右下角的 "Auto" 或当前模型名称，会展开模型列表。点击某个可用模型，即可选择它进行后续对话。

初次使用可以先保留 Auto，熟悉对话流程后再比较不同模型。截图中的模型列表和数字反映的是截图时的界面，不作为固定可用清单或价格承诺。

### 7、按需添加自己的模型

如果已经拥有模型服务商的 API Key，可点击模型列表底部的 "添加模型"，或通过设置进入 "模型" 页面。在模型管理页点击 "＋ 添加模型"。

API Key 是调用模型服务的访问凭证，不是 TRAE 登录密码。没有 API Key 的用户可以跳过这一步，继续使用可用的内置模型。

添加时，根据自己使用的服务选择配置方式：

- 预设服务商：选择服务商、模型，并填写该服务商提供的 API 密钥。
- 自定义模型：按服务商文档填写 API 格式、请求地址、模型 ID 和鉴权信息。

首次配置可以保留高级参数的默认值。添加后，返回对话区选择该模型，发送一句简单问题检查连接。配置失败时，根据错误提示核对密钥、模型 ID 和请求地址。

配置步骤参考：TRAE 内置模型与自定义模型文档。图 7 展示的是模型管理入口，后续表单以实际客户端为准。


## 四、打开你的第一个项目


### 1、新建本地练习目录

在电脑中创建一个空文件夹，命名为 trae-todo。在 TRAE 中点击"打开文件夹"，选择这个目录。

把一个项目放进独立文件夹，便于确认 AI 新建和修改了哪些文件。本教程后续操作都在该目录内进行。


### 2、已有仓库也可以克隆导入

如果项目已托管在 GitHub，可选择"克隆 Git 仓库"，再选择"从 GitHub 克隆"，按照提示授权并选择仓库。

如果你已经知道仓库地址，可以直接粘贴 URL，再选择本地保存位置。


## 五、切换 IDE / SOLO 模式与使用 Agent

TRAE 中有多个工作入口，第一次使用容易混淆。先记住：左上角切换 IDE / SOLO 模式，右上角的 Agent 按钮打开 Agent 窗口。


### 1、从 IDE 切换到 SOLO

在 IDE 模式中，左侧和中间主要用于查看、编辑项目文件，右侧是 AI 对话区域。想一边学习代码、一边修改网页时，可以先使用这个模式。

将鼠标移到左上角的 IDE 标识处，会出现"切换至 SOLO 模式"的提示。点击该入口，即可切换。

切换前建议先打开准备操作的项目文件夹。这样描述"修改当前项目"时，AI 才有明确的工作目录。


### 2、在 SOLO 模式中发起任务

进入后，左上角显示绿色的 SOLO 标识。左侧可以查看任务列表，右侧用于输入需求、阅读执行过程和查看回复。

- 在顶部"选择项目"处确认目标项目。
- 点击左侧 "新任务"，开始一个独立任务。
- 在底部输入具体需求，点击发送按钮。
- 观察执行过程；出现需要确认的操作时，阅读内容后再处理。
- 完成后查看文件变更，并实际运行检查结果。

例如，已有待办事项网页后，可以发送：

```text
请为当前待办事项网页增加“全部、未完成、已完成”三个筛选按钮。
先阅读现有代码，再实现功能。
保留添加、删除和本地保存功能，兼容已有数据。
完成后列出修改的文件，并说明如何检查筛选结果。
```

如果想回到文件编辑界面，使用左上角的模式切换入口返回 IDE。任务列表显示"完成"后，仍需要检查实际效果是否符合要求。


### 3、打开 Agent 窗口

点击窗口右上角的 "Agent ↗"，即可进入 Agent 工作窗口。这个入口与左上角的 IDE / SOLO 模式切换分开。

如果当前只是修改一个函数或查看几行代码，可以继续留在 IDE 中；需要围绕任务集中查看进度时，再尝试 Agent 窗口。


### 4、在 Agent 窗口中创建任务

进入后，可以看到中央的大输入框，以及左侧的"新建任务"、项目和任务列表。右上角的 "IDE ↗" 用于返回 IDE 窗口。

第一次体验，建议沿用本地项目：

- 点击左侧 "新建任务"。
- 确认输入框下方的运行位置为 "本地"。
- 如果任务需要读写文件，点击 "选择文件夹"，选择练习项目目录。
- 输入需求，保留当前可用的默认模型设置，点击向上箭头发送。
- 在左侧任务列表中查看进度。若显示 "待确认"，打开任务查看需要确认的内容。

可以先用一个只分析、不修改文件的任务熟悉流程：

```text
请阅读当前项目，用适合初学者的语言说明：
1. 项目是做什么的。
2. 主要文件分别负责什么。
3. 如何在本地运行。
这次只分析，不修改文件，不安装依赖。
```

## 六、实战：用 AI 制作待办事项网页

下面是为本教程设计的练习，并非官方演示项目。我们使用最基础的 HTML、CSS 和 JavaScript，减少环境配置，把重点放在如何与 AI 协作。


### 1、先让 AI 说明实现思路

确认打开的是 trae-todo 文件夹，在对话区发送：

```text
我要制作一个待办事项网页，支持添加、完成和删除任务，刷新后保留数据。
请用初学者能理解的方式解释 HTML、CSS、JavaScript 各自负责什么，以及 localStorage 如何保存数据。
这一步先说明思路，不修改文件。
```

先理解方案，可以帮助你判断后续生成的文件和代码是否符合预期。


### 2、发送完整需求，创建文件

在对话中选择可执行代码任务的内置智能体。官方文档支持通过输入 @ 或点击当前智能体名称进行选择。发送下面这段提示词：

```text
请在当前文件夹中制作一个中文待办事项网页。

技术要求：
- 使用 HTML、CSS 和原生 JavaScript。
- 创建 index.html、style.css 和 script.js。
- 不使用框架、构建工具、外部 CDN 或后端服务。
- 允许直接用浏览器打开 index.html。

功能要求：
1. 输入内容后点击按钮或按回车添加任务。
2. 不允许添加空白任务。
3. 支持完成、取消完成和删除任务。
4. 显示未完成任务的数量。
5. 使用 localStorage 保存任务及完成状态。
6. 页面重新打开后恢复数据；存储失败时给出提示。
7. 用户输入必须作为普通文本显示。

界面要求：白色背景、绿色按钮、卡片布局，适配手机。
请直接创建文件。完成后说明文件用途、打开方式，以及哪些功能已经验证、哪些需要我手动验证。
```

参考：创建并管理自定义智能体：选择智能体

### 3、打开网页并验收

保存文件后，用浏览器打开 index.html。按下面的顺序检查，不要只看 AI 的完成说明。

- 添加"学习 TRAE"，确认列表出现任务。
- 只输入空格，确认没有创建空白任务。
- 标记任务完成，再取消完成，观察计数是否同步。
- 刷新页面，确认任务和完成状态保留。
- 删除任务后刷新，确认不会重新出现。
- 缩窄浏览器窗口，确认手机宽度下也能操作。
