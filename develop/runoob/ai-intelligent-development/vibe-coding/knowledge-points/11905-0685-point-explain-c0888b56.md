## 原文片段

GitHub Copilot 现在是一个覆盖 IDE、CLI、Github 的 AI 编程平台：在 IDE 里自主编辑多个文件，在云端把 Issue 变成 PR，在终端运行并行子 Agent，在 PR 页面做智能代码审查。
