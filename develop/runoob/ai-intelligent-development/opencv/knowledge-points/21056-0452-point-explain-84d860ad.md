## 原文片段

在 Python 中，可以使用 OpenCV 库来访问图像的像素值。假设我们有一个灰度图像 img，可以通过 img[y, x] 来访问位于 (x, y) 位置的像素值。对于彩色图像，可以通过 img[y, x, c] 来访问特定通道 c 的像素值，其中 c 为 0（蓝色）、1（绿色）或 2（红色）。
