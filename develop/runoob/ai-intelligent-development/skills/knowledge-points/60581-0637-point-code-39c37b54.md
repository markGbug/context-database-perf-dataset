```text
## 迁移指南：从 v1.x 升级到 v2.0

### 主要变化

v2.0 修改了输出文件的命名规则，由原来的 `output.xlsx` 改为带日期的 `output_YYYYMMDD.xlsx`。

### 受影响场景

如果你的工作流依赖固定的输出文件名，需要在使用时重命名文件，或使用 `--output` 参数指定文件名。

### 迁移步骤

1. 更新 Skill 到 v2.0
2. 检查是否有依赖固定文件名的脚本或工作流
3. 如有，添加 `--output output.xlsx` 参数保持旧行为
```
