```text
### 第三步：生成并解读报告

根据 JSON 输出，以人性化方式呈现结果：

1. **总体评级**：A（优秀）/ B（良好）/ C（需改进）/ F（语法错误）
2. **问题汇总表格**：行号、问题代码、描述
3. **Top 3 优先修复项**：选出最严重的 3 个问题，给出修复建议和示例

若文件无问题，给出简短正面评价：
> 代码检查通过！共扫描 X 行，未发现语法错误和明显风格问题。
```

## 学习理解

这段内容需要重点关注输入、执行步骤和输出结果。复习时不要只看代码表面，要说明每一行在完成什么动作。

- 先识别代码使用的语法、命令或 API。
- 再说明关键变量、参数或标签的含义。
- 最后根据代码推导运行结果或页面效果。
