## 本章内容

Ollama 运行模型使用 ollama run 命令。

例如我们要运行 qwen3.5:0.8b 并与该模型对话可以使用以下命令：

首次运行自动下载，约 1.0GB：

```text
ollama run qwen3.5:0.8b
```
