## 本章内容

Hermes Desktop 是官方出品的桌面应用，在命令行工具之上提供了图形化界面——包含可视化 Dashboard、Profile 管理器、技能浏览器等，安装桌面应用时会同时安装命令行工具（hermes 命令），两者可以并用。

- 访问官网 hermes-agent.nousresearch.com
- 点击 Download For ... 按钮
- 运行下载的安装程序，按提示完成安装。

下载后双击安装即可：

安装完成后，hermes 命令会自动添加到系统路径，可以在终端直接使用。

整个面板如下所示：


### 左侧边栏

分为三部分：

- 顶部操作区（新建会话 ⌘N、技能工具、消息平台、Artifacts 入口）。
- 中间搜索栏。
- 底部会话列表，分 PINNED（置顶）和 SESSIONS（普通，显示总数）两组。


### 标题栏

- 居中显示当前会话名称，点击 ∨ 可重命名或管理。
- 右侧图标依次为：语音模式、键盘快捷键、设置（打开 Settings 面板）。


### 对话区

- 主聊天区域，用户消息靠右显示，Agent 回复靠左。
- 回复前可见 Thinking 状态行，表示模型正在推理（当前使用的 kimi-k2.5 支持思维链）。


### 输入框

- 左侧 + 可附加文件/图片。
- 中间占位文字。
- 右侧依次显示当前模型名称 + 推理强度（Med）、麦克风（语音输入）、发送按钮。
- 输入 / 触发斜杠命令补全。


### 底部状态栏

- Gateway ready 网关在线状态。
- Agents 子 Agent 管理。
- Cron 定时任务。
- 右侧为本次会话已用 Token 数、会话时长、版本号 v0.17.0。

## 配置说明

配置面板菜单功能说明：

- 模型：选择对话调用的AI大模型，配置模型参数
- 对话：管理会话历史、上下文窗口与对话留存规则
- 外观（当前页面） 语言：切换桌面客户端界面语言，支持简体中文等语种 明暗模式：明亮/暗色/跟随系统三种显示模式 主题配色：内置 Nous、Midnight 等多款界面色调，还可检索VS Code市场额外主题
- 工作区：划分项目空间，隔离不同场景下的会话与配置
- 安全：设置访问权限、本地数据加密、隐私管控
- 记忆与上下文：配置长期记忆、上下文截断、历史消息携带策略
- 语音：开启语音输入/语音朗读，选择麦克风与TTS语音引擎
- 高级：调试日志、网络代理、本地缓存、实验性功能开关
- 通知：控制消息弹窗、后台提醒与消息推送
- 提供方：配置各大模型服务商API密钥（OpenAI、Anthropic等）
- 网关：接入模型中转网关，统一管理接口地址
- 工具与密钥：配置联网搜索、代码执行等扩展工具，管理第三方密钥
- MCP：对接MCP协议服务，扩展Agent能力
- 已归档对话：查看已封存的历史会话记录
- 关于：查看客户端版本、许可信息与更新入口
