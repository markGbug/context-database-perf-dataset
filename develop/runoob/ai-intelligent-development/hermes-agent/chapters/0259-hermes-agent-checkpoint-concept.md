## 本章内容

本章介绍 Hermes 的三种自动化与安全保障机制：检查点在执行危险操作前保护你的文件，定时任务让 Agent 按计划自主执行，持久目标让 Agent 跨会话推进长期工作。

自动检查点：在执行高风险操作（如大规模文件修改、数据库变更）前，Agent 会自动创建检查点，无需手动干预。

检查点是文件系统级别的快照，适合在让 Agent 执行大规模重构或数据迁移前手动创建一个。它不是 Git 提交的替代品，而是额外的安全保障。

### 持久目标 vs 定时任务

Cron 适合「固定时间做固定的事」，持久目标适合「Agent 你看着办，目标是这个，你自己把握节奏」。两者互补而非替代。
