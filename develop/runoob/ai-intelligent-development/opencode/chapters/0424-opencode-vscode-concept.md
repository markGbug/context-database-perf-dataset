## 其他说明

OpenCode 不仅可以在终端中独立运行，还可以与常见开发工具集成使用，例如 VS Code、Cursor、Windsurf、VSCodium 等。

只要你的 IDE 支持终端，就可以使用 OpenCode。

最简单的方式就是：在 IDE 内置终端中运行 opencode。


### 一、快速开始

在 VS Code 中打开项目后：

- 打开终端（快捷键：Ctrl + `）
- 输入以下命令：

```text
opencode
```

即可进入 OpenCode 界面。
