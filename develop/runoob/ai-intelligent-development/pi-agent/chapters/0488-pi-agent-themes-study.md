## 本章内容

Pi Agent 支持自定义终端界面配色。

本章介绍如何使用内置主题和创建自定义主题。


## 主题概述

Pi Agent 使用 JSON 格式的主题文件来定义 TUI 界面的所有颜色。

每个主题需要定义 51 个必填令牌 + 4 个可选令牌（thinkingMax、scrollbarThumb、searchMatchBg、searchMatchText），覆盖核心 UI、消息背景、Markdown 渲染、语法高亮和编辑器边框等各种界面元素的颜色。

## 颜色令牌分类

colors 中每个令牌对应界面上一类元素的颜色。

下面按用途把全部令牌分成六类，方便对照查找。


### 核心 UI（11 个）

这一组控制编辑器、状态栏等基础界面元素的颜色。


### 背景与内容（11 个必填 + 3 个可选）

这一组控制选中项、消息气泡和工具输出区域的背景与文字。


### Markdown 渲染（10 个）

这一组控制 AI 回复中 Markdown 元素的颜色。


### 语法高亮（9 个）

这一组控制代码块内的语法高亮配色。


### 推理等级边框（7 个）

这一组控制当前推理等级在编辑器边框上的提示色。

thinkingMax 是可选令牌，如果不定义则回退使用 thinkingXhigh 的颜色。


### Diff 与 Bash 配色（4 个）

这一组控制 diff 高亮和 bash 模式提示色，编辑代码时最常看到它们。

## 主题制作技巧

下面几条经验能让自定义主题在不同终端上都表现稳定。

- 深色终端：使用明亮、饱和的颜色，对比度要足够高
- 浅色终端：使用较深、柔和的颜色，对比度可以适当降低
- 色彩和谐：参考 Nord、Gruvbox、Tokyo Night 等成熟配色方案作为基础
- 全面测试：确保在不同消息类型、工具状态、Markdown 内容和长文本折行下都能正常显示
