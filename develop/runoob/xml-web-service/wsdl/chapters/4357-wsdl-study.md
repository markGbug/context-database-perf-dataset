## 本章内容

WSDL（网络服务描述语言，Web Services Description Language）是一门基于 XML 的语言，用于描述 Web Services 以及如何对它们进行访问。

现在开始学习 WSDL!

WSDL 绑定 本章讲解 WSDL binding interface。

WSDL 和 UDDI 本章讲解 UDDI 如何与 WSDL 进行整合。(UDDI: Universal Description Discovery and Integration.)
