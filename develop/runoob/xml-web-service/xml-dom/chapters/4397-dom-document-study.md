## 本章内容

Document 对象代表整个 XML 文档。


## Document 对象

Document 对象是文档树的根，并为我们提供对文档数据的最初（或最顶层）的访问入口。

由于元素节点、文本节点、注释、处理指令等均无法存在于文档之外，Document 对象也提供了创建这些对象的方法。Node 对象提供了一个 ownerDocument 属性，此属性可把它们与在其中创建它们的 Document 关联起来。
