NamedNodeMap 对象代表一个节点的无序列表。


## NamedNodeMap 对象

NamedNodeMap 中的节点可以通过它们的名称进行访问。

NamedNodeMap 将会自我更新。如果在节点列表或 XML 文档中删除或添加一个元素，那么该列表将会自动更新。

注意：在命名节点图中，节点不会以任何特定的顺序返回。
