## 本章内容

NodeList 对象代表一个有序的节点列表。


## NodeList 对象

节点列表中的节点可以通过其对应的索引数字（从 0 开始计数）进行访问。

节点列表可保持其自身的更新。如果节点列表或 XML 文档中的某个元素被删除或添加，列表也会被自动更新。

注意：在一个节点列表中，节点被返回的顺序与它们在 XML 文档中被规定的顺序相同。
