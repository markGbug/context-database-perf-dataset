## Attr 对象

Attr 对象表示 Element 对象的属性。属性的容许值通常定义在 DTD 中。

由于 Attr 对象也是一种节点，因此它继承 Node 对象的属性和方法。不过属性无法拥有父节点，同时属性也不被认为是元素的子节点，对于许多 Node 属性来说都将返回 null。
