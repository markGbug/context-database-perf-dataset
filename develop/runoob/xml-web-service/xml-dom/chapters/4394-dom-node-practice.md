## Node 对象

Node 对象代表文档树中的一个单独的节点。

这里的节点可以是：元素节点、属性节点、文本节点以及所有在 节点类型这章中所提到的所有其他的节点类型。

请注意，尽管所有的对象都继承了用以处理父节点和子节点的 Node 属性 / 方法，但是并不是所有的对象都可以包含父节点或子节点。举个例子来说，Text 节点中可能不包含子节点，所以把子节点添加到文本节点中可能会导致一个 DOM 错误。
