## 对数值数据类型的限定（Restriction）

可与数值数据类型一同使用的限定：

- enumeration
- fractionDigits
- maxExclusive
- maxInclusive
- minExclusive
- minInclusive
- pattern
- totalDigits
- whiteSpace
