只能当其他人能够找到您的 RSS 文档时，它才是有用的。


## 把您的 RSS 发布到 Web 上

现在是时候把您的 RSS 文件上传到网上了。下面是具体的步骤：

1.为您的 RSS 命名。请注意文件必须有 .xml 的后缀。

2. 验证您的 RSS 文件。（可以在 http://www.feedvalidator.org 找到很好的验证器）。

3. 把 RSS 文件上传到您的 web 服务器上的 web 目录。

4. 把这个小的橙色按钮 或 拷贝到您的 web 目录。
