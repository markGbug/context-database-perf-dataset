## 选择和过滤元素

正如在前面的章节所看到的，我们使用路径表达式或 FLWOR 表达式来选取和过滤元素。

请看下面的 FLWOR 表达式：

- for - （可选） 向每个由 in 表达式返回的项目捆绑一个变量
- let - （可选）
- where - （可选） 设定一个条件
- order by - （可选） 设定结果的排列顺序
- return - 规定在结果中返回的内容
