双下划线 __ 是 Django ORM 的核心约定：用于访问关联模型的字段、或指定字段的查询方式。例如 category__slug 表示跨越外键到 Category 表的 slug 字段。

分类按钮的链接同时保留了 category 和 keyword 参数：?category={{ cat.slug }}&q={{ keyword }}。这样用户先搜索再点分类后，搜索条件不会丢失，两个条件同时生效。
