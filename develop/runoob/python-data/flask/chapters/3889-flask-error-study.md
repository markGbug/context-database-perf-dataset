## 本章内容

Flask 提供了灵活的错误处理机制，可以捕获并处理应用中的各种错误。

优秀的错误处理不只是「不出 Bug」，更是当 Bug 发生时，给用户一个友好的体验。

本章介绍 Flask 中如何自定义错误页面和管理日志。
