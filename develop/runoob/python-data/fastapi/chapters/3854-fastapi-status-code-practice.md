## 小结

- 使用装饰器的 status_code 参数声明默认状态码
- 推荐使用 fastapi.status 常量，有编辑器自动补全支持
- POST 创建资源用 201，DELETE 删除资源用 204，GET 获取资源用 200
- 4xx 表示客户端错误，5xx 表示服务器错误
