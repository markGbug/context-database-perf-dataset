## 小结

路径参数数值校验的核心要点：

- 使用 Annotated + Path 声明路径参数的校验规则
- 数值校验：gt（大于）、ge（大于等于）、lt（小于）、le（小于等于）
- Path 和 Query 共享相同的校验参数，包括字符串校验（min_length 等）和元数据（title、description 等）
- 路径参数始终是必填的，无论是否声明默认值
