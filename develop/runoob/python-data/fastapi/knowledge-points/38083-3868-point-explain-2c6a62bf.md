## 原文片段

str | None = Query(None) 是 Python 3.10+ 的类型联合语法，等价于 Optional[str]。FastAPI 会根据类型提示自动：1. 使参数可选；2. 在 Swagger 文档中标记为可选；3. 不传时不报错。
