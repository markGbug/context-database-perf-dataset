## 原文片段

Pydantic 模型与 SQLAlchemy 模型是分离的。Pydantic 负责 API 层的数据校验，SQLAlchemy 负责数据库层的表结构。from_attributes=True 让 Pydantic 能够从 SQLAlchemy 对象中读取数据。
