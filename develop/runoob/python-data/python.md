## 推荐学习顺序

1. 先读入门、简介、环境安装或快速开始，确认它解决的问题和适用边界。
2. 逐章整理核心概念，把每个概念写成“用途、语法/配置、常见错误、示例”四块。
3. 对 API、命令或语法点做最小可运行示例，优先使用官方教程中的示例结构。
4. 完成一个小型综合练习，把多个章节串起来，形成可复查的代码或操作记录。
5. 回头补性能、安全、调试、部署、兼容性等进阶主题。

## 练习清单

- 用自己的话解释 Python 的主要用途和典型使用场景。
- 跟做教程中的基础示例，并记录运行环境、命令和输出。
- 挑 3 个核心章节写最小示例，保证以后能快速回忆。
- 故意制造一个常见错误，记录报错信息、定位方法和修复步骤。
- 做一个 30 到 60 分钟的小项目或小实验，把零散知识串起来。
