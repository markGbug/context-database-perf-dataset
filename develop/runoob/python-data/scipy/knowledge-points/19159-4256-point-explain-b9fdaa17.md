## 原文片段

NumPy 本身主要关注数组计算和线性代数运算，它提供了用于多项式求根的工具（如 numpy.roots）， 但并未提供通用的非线性方程数值求根接口。当我们需要求解一般形式的非线性方程时，就需要使用 SciPy 的优化模块。
