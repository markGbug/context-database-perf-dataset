## 原文片段

ImageOps 是 Python Pillow 图像处理库中的一个实用模块，它提供了一系列预定义的图像处理操作。这些操作通常是对 PIL.Image 模块功能的封装和简化，让开发者能够用更简洁的代码实现常见的图像处理需求。
