## 本章内容

多重派发（multiple dispatch）是 Julia 最核心的语言特性：同一个函数可以针对不同参数类型的组合定义多个实现（方法），调用时根据所有参数的类型选择最匹配的实现。

这与传统面向对象语言不同：C++、Java、Python 的方法派发只看第一个参数（this 对象），而 Julia 的函数不属于任何类型，派发时会考虑全部参数。
