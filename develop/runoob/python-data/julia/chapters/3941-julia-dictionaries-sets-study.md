除了数组和元组，Julia 还提供了两种常用的集合：字典（Dict）和 Set（无序集合）。


## 字典

字典是一种可变容器模型，且可存储任意类型对象。

字典的每个键值对用 => 分割，每个键值对之间用逗号 , 分割，整个字典包括在花括号 {} 中。


### 创建字典

创建字典的语法格式如下：

```text
Dict("key1" => value1, "key2" => value2, ..., "keyn" => valuen)
```
