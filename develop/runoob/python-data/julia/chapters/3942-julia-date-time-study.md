## 本章内容

Julia 通过标准库 Dates 模块提供了以下三个类型来处理日期和时间：

- Date：表示日期，精确到日，只显示日期。
- DateTime：表示日期和时间，精确到毫秒。
- Time：表示日时间，精确到纳秒，代表一天 24 小时中的特定时刻。

使用前，我们需要先导入 Dates 模块：

```text
using Dates
```

Date 和 DateTime 类型可以通过整数或 Period 类型解析。

Period 基于日期值，表示年、月、日等时间段：

```text
Year        # 年
Quarter     # 季度
Month       # 月
Week        # 周
Day         # 日
Hour        # 小时
Minute      # 分钟
Second      # 秒
Millisecond # 毫秒
Microsecond # 微秒（仅 Time）
Nanosecond  # 纳秒（仅 Time）
```

Date 和 DateTime 都是抽象类型 TimeType 的子类型。
