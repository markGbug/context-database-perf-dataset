## 本章内容

流程控制语句通过程序设定一个或多个条件语句来实现。在条件为 true 时执行指定程序代码，在条件为 false 时执行其他指定代码。

Julia 提供了大量的流程控制语句：

- 复合表达式：begin 和 ;。
- 条件表达式：if-elseif-else 和 ?: (三元运算符)。
- 短路运算：逻辑运算符 &&（与）和 ||（或），以及链式比较。
- 循环语句：while 和 for。
- 异常处理：try-catch、error 和 throw。
- Task（协程）：非局部控制流，详见 Task 与并发。

当使用 if...elseif...else 语句时，以下几点需要注意：

- 一个 if 后可跟零个或一个 else，else 必须在所有 elseif 之后。
- 一个 if 后可跟零个或多个 elseif，elseif 必须在 else 之前。
- 一旦某个条件匹配成功，其他的 elseif 或 else 将不会被测试。
- 每个 if 块必须以 end 结束。

### 三元运算符

三元运算符 ?: 类似 if-elseif-else 语法：

```text
a ? b : c
```

在 ? 之前的表达式 a 是一个条件表达式，如果条件 a 是 true，三元运算符计算在 : 之前的表达式 b；如果条件 a 是 false，则执行 : 后面的表达式 c。

注意：? 和 : 旁边的空格是强制的，像 a?b:c 这种表达式不是有效的三元表达式。

## 短路运算

Julia 中的 && 和 || 运算符分别对应于逻辑"与"和"或"操作。

- 在表达式 a && b 中，子表达式 b 仅当 a 为 true 的时候才会被执行。
- 在表达式 a || b 中，子表达式 b 仅在 a 为 false 的时候才会被执行。
