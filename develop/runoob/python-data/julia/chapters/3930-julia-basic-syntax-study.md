## 变量命名规则

Julia 变量名大小写敏感，命名规则如下：

- 变量名必须以字母（A-Z、a-z）、下划线 _ 或部分 Unicode 字符开头，首字符不能是数字。
- 后续字符可以包含字母、数字、下划线、感叹号 ! 等。
- 变量名区分大小写，Runoob 和 runoob 是两个不同的变量。

## 赋值与修改的区别

这是 Julia 初学者最容易混淆的概念之一：赋值（assignment）是给值起一个新名字，而修改（mutation）是改变对象本身的内容。

对整数等不可变类型，a = 2; a = 3 只是把名字 a 指向了新值 3，数字 2 本身没有任何变化。

以感叹号 ! 结尾的函数叫做"修改（mutating）"或"原位（in-place）"函数，它们会修改输入参数的内容而不只是返回一个新值，例如 sort(v) 返回排序后的新数组，而 sort!(v) 直接原地修改数组 v。
