## 本章内容

Julia 的元组与数组类似，都是有序的元素集合，不同之处在于元组的元素不能修改，元组是不可变类型。

另外元组使用小括号 (...)，数组使用方括号 [...]。

元组创建很简单，只需要在括号中添加元素，并使用逗号隔开即可，数组中的很多函数也可以在元组中使用。
