## 实例

Channel 的关键行为：

- 通道满了，put! 会阻塞等待空位；通道空了，take! 会阻塞等待数据。
- put! 和 take! 是线程安全的，多个任务可以同时读写同一个通道。
- close(ch) 关闭通道，关闭后不能再 put!，但可以先取完已有的数据。
