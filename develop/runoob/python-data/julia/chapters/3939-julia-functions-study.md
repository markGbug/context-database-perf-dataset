## 本章内容

函数是一组一起执行一个任务的语句。

在 Julia 里，函数是将参数值组成的元组映射到返回值的一个对象。


## 定义函数

Julia 中使用 function 定义函数，基本语法是：

```javascript
function functionname(args)
   expression
   ...
end
```
