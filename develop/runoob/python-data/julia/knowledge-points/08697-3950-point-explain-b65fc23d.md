## 原文片段

Julia 的性能来自类型推断和 JIT 编译：编译器需要知道每个值的类型才能生成高效代码。因此 Julia 的性能问题几乎都源于"编译器猜不出类型"，掌握了这一点，写出接近 C 速度的代码并不难。
