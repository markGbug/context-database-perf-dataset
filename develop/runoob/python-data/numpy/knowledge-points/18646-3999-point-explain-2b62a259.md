## 原文片段

numpy.matlib 专门用于创建和操作 矩阵（matrix） 对象。虽然 NumPy 的核心支持多维数组（ndarray），numpy.matlib 提供了一些方便的函数，专门返回矩阵类型，便于用户进行传统的线性代数运算。
