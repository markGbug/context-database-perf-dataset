## 本章内容

集合（Set）是 Python 中的一种内置容器类型，用于存储多个不重复的元素。

集合具有以下特点：

- 元素不重复：相同的元素只会保留一份。
- 无序：元素没有固定的排列顺序，不支持通过索引访问。
- 元素必须可哈希：可以包含整数、字符串、元组等符合条件的对象，但不能直接包含列表、字典等不可哈希对象。
- 支持集合运算：可以进行并集、交集、差集、对称差集等操作。
- 可以修改：普通 set 支持添加和删除元素。

集合常用于数据去重、成员判断以及多个数据集合之间的比较。

### 集合自动去重

集合中的元素不会重复，因此可以利用 set() 对列表等可迭代对象进行去重。


## 实例

执行结果：

```text
[1, 2, 3, 4, 5]
```

需要注意，转换为集合后，原有元素的排列顺序不会得到保证。

如果需要对列表去重并保留原有顺序，可以使用：

```text
numbers = [3, 1, 2, 3, 2, 4]

result = list(dict.fromkeys(numbers))

print(result)
```

执行结果：

```text
[3, 1, 2, 4]
```

上述保序去重方法要求元素可以作为字典键使用，适用于 Python 3.7 及以上版本。


### 集合元素的类型限制

集合中的元素必须是可哈希（Hashable）的对象。

常见的可哈希对象包括整数、浮点数、字符串，以及所有成员都可哈希的元组。

```text
my_set = {1, 3.14, "Python", (1, 2)}

print(len(my_set))
```

执行结果：

```text
4
```

列表、字典和普通集合通常不可哈希，不能直接作为集合元素。

```text
my_set = {[1, 2], [3, 4]}

# TypeError: unhashable type: 'list'
```

如果需要将一个集合作为另一个集合的元素，可以使用不可变集合 frozenset。

## 集合推导式

与列表推导式类似，Python 也支持集合推导式（Set Comprehension），可以使用简洁的语法创建集合。

基本语法：

```text
{expression for item in iterable if condition}
```

其中，if condition 是可选条件。


## 实例

执行结果：

```text
[1, 4, 9, 16, 25]
['d', 'r']
```

集合推导式也会自动去除重复元素。


## 集合的基本操作


### 1、添加元素

可以使用 add() 方法向集合添加一个元素。

语法格式：

```text
s.add(x)
```

如果元素已经存在，集合不会发生变化，也不会报错。


## 实例

执行结果：

```text
['Facebook', 'Google', 'Runoob', 'Taobao']
```

如果需要一次添加多个元素，可以使用 update()。

语法格式：

```text
s.update(iterable1, iterable2, ...)
```

update() 可以接收一个或多个可迭代对象，将其中的元素加入当前集合。


## 实例

执行结果：

```text
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

注意：如果向 update() 传入字典，添加的是字典的键，而不是值。

```text
s = {1, 2}
s.update({"a": 10, "b": 20})

print(sorted(s, key=str))
```

输出结果：

```text
[1, 2, 'a', 'b']
```

如果想添加字典的值，可以使用 dict.values()，前提是这些值可以作为集合元素。


### 2、移除元素

集合提供了 remove()、discard() 和 pop() 等删除方法。

remove() 用于删除指定元素。如果元素不存在，会抛出 KeyError 异常。

语法格式：

```text
s.remove(x)
```


## 实例

执行结果：

```text
['Google', 'Runoob']
Traceback (most recent call last):
...
KeyError: 'Facebook'
```

discard() 同样用于删除指定元素，但如果元素不存在，不会抛出异常。

语法格式：

```text
s.discard(x)
```


## 实例

执行结果：

```text
['Google', 'Runoob']
```

pop() 用于从集合中移除并返回一个任意元素。

语法格式：

```text
s.pop()
```


## 实例

执行结果：

```text
移除的元素属于原集合： True
剩余元素个数： 3
```

注意：pop() 并不是随机抽样函数，也不是删除集合中的第一个元素。集合没有固定顺序，因此不能预测它会返回哪个元素。

如果集合为空，调用 pop() 会抛出 KeyError 异常。


### 3、计算集合元素个数

可以使用 len() 函数获取集合中的元素数量。

语法格式：

```text
len(s)
```


## 实例

执行结果：

```text
3
3
```

因为集合不会保存重复元素，所以再次添加 "Google" 后，元素个数不变。


### 4、清空集合

可以使用 clear() 方法删除集合中的所有元素。

语法格式：

```text
s.clear()
```


## 实例

执行结果：

```text
set()
0
```

这里输出的 set() 表示一个空集合。


### 5、判断元素是否在集合中

可以使用 in 和 not in 运算符判断元素是否属于集合。

语法格式：

```text
x in s
x not in s
```


## 实例

执行结果：

```text
True
False
True
```

集合通常基于哈希表实现，因此成员判断在一般情况下具有较高效率，平均时间复杂度通常为 O(1)，但最坏情况下可能退化。
