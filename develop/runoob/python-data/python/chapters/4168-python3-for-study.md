## 本章内容

Python3 循环语句

for 是 Python 中最常用的循环语句，用于遍历可迭代对象（序列、字典、集合等）。

Python 的 for 循环比 C/C++ 等语言更加简洁和强大，不需要手动管理循环变量，直接遍历元素。

单词释义： for 意为"为、对于"，用于迭代遍历。


## 基本语法与参数


### 语法格式

```text
for 变量 in 可迭代对象:
    代码块
```


### 语法说明

- 变量： 每次循环从可迭代对象中取出的元素。
- 可迭代对象： 列表、元组、字符串、字典、集合、range 等。
- 缩进： 循环体必须缩进。


### else 子句

- 可选： for 循环可以有 else 子句。
- 执行时机： 循环正常结束（未通过 break 退出）时执行。
