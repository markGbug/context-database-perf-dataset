## 原文片段

想象一下，你给朋友寄一个包裹。如果你在包裹上写明"易碎品"和"向上箭头"，快递员就会知道要小心轻放、正确朝向。类型注解（Type Hints） 在编程中就扮演着类似的角色——它是一种为代码添加"说明标签"的技术，明确地指出变量、函数参数和返回值应该是什么数据类型。
