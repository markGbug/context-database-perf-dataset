## 原文片段

ECharts 是一个基于 JavaScript 的开源数据可视化库，提供丰富的图表类型和交互功能。pyecharts 对 ECharts 进行了 Python 封装，使开发者无需直接编写复杂的 JavaScript 代码，就能创建功能丰富的数据可视化图表。
