## 原文片段

DateOffset 支持多种参数，可以指定增加或替换的时间单位，如年、月、周、日、小时、分钟、秒等。这些参数可以是增加到偏移值的（如 years、months、weeks、days、hours、minutes、seconds 等），也可以是替换偏移值的（如 year、month、day、weekday、hour、minute、second 等）。
