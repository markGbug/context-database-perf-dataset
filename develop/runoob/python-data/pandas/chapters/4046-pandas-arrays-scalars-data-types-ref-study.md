## 本章内容

对于大多数数据类型，Pandas 使用 NumPy 数组作为具体的存储对象，这些对象被包含在 Index（索引）、Series（序列）或 DataFrame（数据框）中。

对于某些数据类型，Pandas 扩展了 NumPy 的类型系统。这些类型的字符串别名可以在 dtypes 中找到。
