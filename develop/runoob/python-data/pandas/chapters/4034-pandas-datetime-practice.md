## 常见问题

1、日期格式不统一

使用 pd.to_datetime 时可以指定 format 参数明确格式，避免解析错误。

2、时区混淆

跨时区数据处理时，确保所有时间使用统一的时区或 UTC 时间。

3、日期运算使用 Timedelta

日期加减使用 pd.Timedelta，而不是简单的整数加减。

处理时间序列数据时，建议尽早将日期字符串转换为 datetime 类型，以便利用 Pandas 强大的日期功能。
