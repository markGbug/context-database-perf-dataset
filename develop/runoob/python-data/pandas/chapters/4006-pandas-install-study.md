## 本章内容

安装 pandas 需要基础环境是 Python，Pandas 是一个基于 Python 的库，因此你需要先安装 Python，然后再通过 Python 的包管理工具 pip 安装 Pandas。

使用 pip 安装 pandas:

```text
pip install pandas
```

安装成功后，我们就可以导入 pandas 包使用：

```text
import pandas
```


## 实例 - 查看 pandas 版本

导入 pandas 一般使用别名 pd 来代替：

