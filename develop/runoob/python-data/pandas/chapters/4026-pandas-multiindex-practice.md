## 常见问题与注意事项

1、索引层次混乱

操作数据时要小心，避免层次错乱。建议在操作前后检查 df.index.names。

2、索引访问错误

loc 使用标签访问，iloc 使用位置访问，两者不要混用。

3、concat 时索引重复

使用 concat 合并数据时，若有重复索引可能导致意外结果，可使用 ignore_index=True 重置。

多层索引是 Pandas 处理高维数据的核心功能。合理使用多层索引可以让数据组织更清晰，统计更便捷。
