## 注意事项

1、处理缺失值

字符串操作默认会跳过缺失值（NaN），如果需要处理，可以使用 .fillna() 先填充。

2、大小写敏感

大部分函数默认大小写敏感，使用 case=False 参数可以进行不区分大小写的匹配。

3、正则表达式性能

正则表达式功能强大但相对较慢，处理大数据量时注意性能。

字符串处理是数据清洗的重要环节，合理使用 .str 访问器可以高效完成大部分文本处理任务。
